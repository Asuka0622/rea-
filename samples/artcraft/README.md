# ArtCraft 开源演示源码

本目录保存七款 ArtCraft 软件的固定版本完整官方源码，供 REA 工作台学习软件结构。总大小约 213.5 MiB，不含编译依赖、构建产物或安装版软件。

在首页点击「探索 ArtCraft 开源演示」，再选择「分析源码」。新手模式在分析完成后开箱领取报告，专业模式直接显示报告。报告来自本机 Cargo 清单及文件扫描；扫描不会编译或运行这些源码，也不进行完整依赖解析。

`SOURCES.json` 保存官方仓库、固定提交、下载链接、取得日期和压缩包 SHA-256。各目录保留上游 MIT 与 Apache 2.0 许可证。`printcraft` 是 PdfCraft 的上游仓库名称。

需要真实编辑图片、矢量或视频时，使用工作台提供的官方体验入口。若本地源码缺失，可运行项目根目录的 `scripts/prepare-artcraft.ps1` 按记录的固定版本重新下载。
