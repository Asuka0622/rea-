# 防御墙数值 Mod

工作台原创教学样本，非上游官方游戏 Demo。

## 使用
在 Mindustry 的 Mods 页面导入导出的 ZIP，重启游戏。在沙盒模式测试训练墙；研究树挂在 copper-wall 下。声明最低构建版本 146，仍需在你的安装版本内验证兼容性。

## 数值
- 建筑生命: 400
- 护甲: 2
- 铜建造成本: 6

API 依据：https://mindustrygame.github.io/wiki/modding/1-modding/

Luanti/Mindustry 模组仅校验文件结构与数值生成，未进行真实游戏内加载验证。请在游戏中测试平衡与兼容性。网页版已可直接试玩。
