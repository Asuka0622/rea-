# 回血食物与配方 Mod

工作台原创教学样本，非上游官方游戏 Demo。

## 使用
需要 Luanti 5.9+ 和 Minetest Game（含 default 模组）。解压到用户 mods/rea_healing_food 并启用。两个 default:apple 可无序合成点心；/giveme rea_healing_food:snack 可直接取得。启用伤害后测试回血。

## 数值
- 单份回复生命: 4
- 合成产量（份）: 1

API 依据：https://api.luanti.org/core-namespace-reference/

Luanti/Mindustry 模组仅校验文件结构与数值生成，未进行真实游戏内加载验证。请在游戏中测试平衡与兼容性。网页版已可直接试玩。
