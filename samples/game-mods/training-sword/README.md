# 训练剑 Mod

工作台原创教学样本，非上游官方游戏 Demo。

## 使用
需要 Luanti 5.9+ 和 Minetest Game（含 default 模组）。解压到用户 mods/rea_training_sword，进入世界设置启用。用 /giveme rea_training_sword:sword 取得训练剑；需 giveme 权限。

## 数值
- 满蓄力伤害: 6
- 攻击间隔（秒）: 1
- 攻击耐久（次）: 100

API 依据：https://api.luanti.org/tool-capabilities/

Luanti/Mindustry 模组仅校验文件结构与数值生成，未进行真实游戏内加载验证。请在游戏中测试平衡与兼容性。网页版已可直接试玩。
