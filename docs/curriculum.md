# 比特镇课程大纲：把计算机学科的知识都装进来

> 2026-10-15，小克整理。目的：对照权威课程标准，找出游戏里还缺哪些计算机知识，并规划放进小镇的哪个地方、由谁来教。
> 现有的五条技能主干在 `public/game-skills.js`；剧情设计在 `docs/story.md`。

## 1. 参考了哪些标准

| 标准 | 是什么 | 结构 |
|---|---|---|
| **CS2023**（ACM、IEEE 计算机学会、AAAI 联合制定） | 目前最新的大学计算机专业课程指南 | 17 个知识领域 |
| **CSTA K-12 计算机标准**（2017 修订版） | 美国中小学计算机课程标准 | 5 个概念：计算系统、网络与互联网、数据与分析、算法与编程、计算的影响 |
| **普通高中信息技术课程标准**（2017 年版） | 我国高中信息技术课 | 必修：数据与计算、信息系统与社会；选择性必修：数据与数据结构、网络基础、数据管理与分析、人工智能初步、三维设计与创意、开源硬件项目设计；选修：算法初步、移动应用设计 |

CS2023 的 17 个知识领域：
1. 算法基础（AL）
2. 体系结构与组成（AR）
3. 人工智能（AI）
4. 数据管理（DM）
5. 程序设计语言基础（FPL）
6. 图形与交互技术（GIT）
7. 人机交互（HCI）
8. 数学与统计基础（MSF）
9. 网络与通信（NC）
10. 操作系统（OS）
11. 并行与分布式计算（PDC）
12. 安全（SEC）
13. 社会、伦理与职业（SEP）
14. 软件开发基础（SDF）
15. 软件工程（SE）
16. 专门平台开发（SPD）
17. 系统基础（SF）

## 2. 现在有什么、缺什么

| CS2023 领域 | 我们现在 | 缺口 |
|---|---|---|
| 体系结构（AR）、系统基础（SF） | 「电脑」主干：二进制、电脑组成、内存和硬盘、CPU | 逻辑门、电路、汇编、存储层次 |
| 操作系统（OS） | 「电脑」里只有进程、操作系统两格 | 文件系统、权限、命令行、线程、虚拟机和容器 |
| 软件开发基础（SDF）、程序设计语言（FPL） | 「编程」主干 | 编译和解释、类型、递归、函数式、事件驱动 |
| 算法基础（AL） | 只有「查找与排序」一格 | **整块缺**：复杂度、栈和队列、树、图、寻路、贪心、动态规划、计算理论 |
| 网络与通信（NC） | 「网络」主干 | 无线、物联网通信 |
| 安全（SEC） | 「安全」主干（REA 支线） | 密码学原理、网络攻击类型 |
| 人工智能（AI） | 「AI」主干 | 搜索与博弈、强化学习 |
| 数据管理（DM） | **没有** | 表格、数据库、SQL、数据清洗、可视化、大数据 |
| 数学与统计（MSF） | **没有** | 布尔逻辑、集合、概率统计、图论、坐标和向量 |
| 图形与交互（GIT） | 只有「像素与颜色」一格 | 图像处理、动画、3D、音频和视频 |
| 人机交互（HCI） | **没有** | 界面设计、无障碍、用户研究 |
| 软件工程（SE） | **没有** | 版本控制、测试、协作、开源 |
| 并行与分布式（PDC） | 只有「云服务器」一格 | 并发、多核、分布式系统 |
| 专门平台开发（SPD） | **没有** | 手机 App、网页前端、游戏开发、嵌入式和机器人 |
| 社会、伦理与职业（SEP） | 散在安全和 AI 里 | 版权和开源许可、数字足迹、计算机历史、职业 |

另外两样标准里有、对新手特别有用的：
- **数字素养**：搜索技巧、辨别网上信息真假、文件管理。CSTA 和高中课标都很重视。
- **计算思维**：分解问题、找规律、抽象、设计步骤。适合贯穿所有主干，不单列一条。

## 3. 建议：从 5 条主干扩成 14 条，分进 5 个「学院」

技能树一页一条主干，14 页太多，所以按学院分组：先选学院，再选主干。每条主干 10–14 个技能，用直白的名字；有趣的名字留给成就。

## 4. 放进剧情的方式

- **主线（停摆的钟楼）只走核心路线**：电脑 → 编程 → 网络 → 安全 → AI，保持现在的五章。
- **其余主干都做成分区支线**：每位师傅一条支线，主线经过时解锁。例如：
  - 第一章打开钟楼后，解锁白医生的「系统」支线和书奶奶的「算法」支线。
  - 第二章学会编程后，解锁阿木的「软件工程」和像素哥的「游戏与交互」。
  - 第三章学会网络后，解锁周姐的「数据」和阿信的「分布式与云」。
  - 第五章之后，解锁老秦的「社会与历史」全集。
- **数学不单独上课**：「数学」主干的技能分散在其他小游戏里顺带学。比如二进制灯就同时点亮数学的「进制换算」，寻路就同时点亮「图论」。南岸天文台另有一条短支线，把这些串起来讲。
- **数字素养放在开头**：书奶奶的新手角，第一次进图书馆就能学，帮完全零基础的人起步。

## 5. 建议的制作顺序

1. **技能树改版**：加上「学院」一层，把 14 条主干的大纲（只要名字和简介，`from` 留空）先填进 `game-skills.js`，让玩家一打开就能看到完整的学习地图。
2. **继续主线第二章**（编程），把「算法」和「系统」两条支线的前几格接上。
3. **数据支线**（周姐）：和办公楼的剧情一起做，北区就不会空着。
4. **图形与多媒体、游戏与交互**：和手艺街的画室、游戏厅一起开张。
5. 其余主干按玩家反馈排序。

## 6. 需要新增的地点和角色（以后写进美术文档）

- **南岸天文台**（数学）：南岸草地上的小圆顶建筑。新角色「观星人」。
- **木工坊二楼工程队**（软件工程）：可以只是室内多一个房间。
- **驿站分拣中心**（分布式与云）：驿站的后屋。
- **手办店改为创客工坊**（硬件创客）：门口加机械臂和电路板招牌。
- **办公楼数据部**（数据）：周姐办公楼的一层。
