# 第一部知识大纲：人工智能

> 2026-10-16。比特镇系列第一部（`docs/concept.md`）只讲人工智能。这份大纲也是技能树的蓝本：**六条主干，每条一页**，技能名直白，有趣的名字留给成就。
> 全学科的旧大纲留档在 `docs/archive/curriculum-all-subjects.md`。

## 1. 参考了哪些标准

| 标准 | 用来对照什么 |
|---|---|
| **CS2023** 的「人工智能（AI）」知识领域（ACM、IEEE 计算机学会、AAAI） | 大学层面 AI 的核心知识：搜索、知识表示与推理、机器学习、应用与社会影响 |
| **AI4K12「AI 的五个大概念」**（感知、表示与推理、学习、自然交互、社会影响） | 面向中小学的 AI 学什么、学到多深 |
| **普通高中信息技术课程标准**（2017 年版）选择性必修「人工智能初步」 | 国内高中 AI 课的范围 |
| 联合国教科文组织《K-12 AI 课程》报告（2022） | AI 伦理、责任与素养 |

## 2. 知识范围（来自剧情调整说明）

- **AI 前史与起点**：程序和通用机器、符号处理、「机器能思考吗」、模仿游戏、AI 学科的诞生。
- **符号 AI 与专家系统**：知识表示、规则推理、不确定性、搜索、博弈。
- **机器学习**：训练数据、特征、分类与预测、过拟合、模型评估。
- **深度学习**：神经网络、反向传播的直觉、卷积看图、强化学习和自我对弈。
- **生成式 AI**：词元、预测下一个词、注意力、预训练和微调、多模态、检索增强、工具调用、幻觉与核实。
- **AI 应用与责任**：隐私、权限、数据安全、公平、版权、可靠性、AI 安全、人工复核。REA 委托里的调查方法也归在这里。

## 3. 技能树：六条主干

每条主干一页，每页 12–14 个技能。「从哪学」写的是主线或委托里第一次学会它的地方；标「深入」的只在硬核难度的主线出现，其他难度在通关后补学。

### 主干一 · AI 是什么（前史与起点）

| 技能 | 一句话 | 从哪学 |
|---|---|---|
| 程序是步骤 | 机器照着一步步的指令做事 | 时代一 |
| 通用机器 | 同一台机器，换一套指令就能做别的事 | 时代一 |
| 符号不只是数字 | 数字可以代表字母、音符、棋子 | 时代一 |
| 机器能创造吗 | 爱达的问题：机器只能做我们让它做的事吗 | 时代一 |
| 机器能思考吗 | 把一个说不清的问题，换成能检验的问题 | 时代二 |
| 模仿游戏 | 隔着屏幕聊天，分不出人和机器 | 时代二 |
| 模仿游戏的局限 | 骗过人不等于懂；测试能被技巧钻空子 | 时代二 |
| AI 成为学科 | 1956 年，一群人决定专门研究「让机器智能」 | 时代二 |
| 强 AI 和弱 AI | 在一件事上聪明，和什么都会，是两回事 | 时代四 |
| AI 的冬天（深入） | 期望太高、成果不够时，经费和热情都会退潮 | 时代三 |

### 主干二 · 搜索与推理（符号 AI）

| 技能 | 一句话 | 从哪学 |
|---|---|---|
| 状态和搜索 | 把问题画成一张「所有可能」的地图，再找路 | 时代二 |
| 知识表示 | 把专家知道的东西写成机器能用的样子 | 时代三 |
| 规则 | 「如果……那么……」 | 时代三 |
| 推理链 | 规则一条接一条，从线索推到结论 | 时代三 |
| 不确定性 | 证据不够时，给结论打个「有几分把握」 | 时代三 |
| 解释 | 系统能说出「为什么这么判断」 | 时代三 |
| 规则的边界 | 规则外的情况就出错；知识难写全 | 时代三 |
| 博弈树 | 你走一步，我走一步，所有可能长成一棵树 | 时代四 |
| 评估函数 | 走不到终局时，给局面打分 | 时代四 |
| 剪枝 | 明显不好的分支就不往下算 | 时代四 |
| 算力换智能 | 每秒算两亿步，靠的是算得多 | 时代四 |
| 极小极大（深入） | 假设对手也走最好的一步 | 时代四 |

### 主干三 · 机器学习

| 技能 | 一句话 | 从哪学 |
|---|---|---|
| 从例子里学 | 不写规则，给大量例子让机器自己找规律 | 时代五 |
| 训练数据 | 学到什么，取决于喂了什么 | 时代五 |
| 标注 | 给例子写上正确答案 | 时代五 |
| 特征 | 判断时看的是哪些线索 | 时代五 |
| 分类 | 把东西分到几个类别里 | 时代五 |
| 预测 | 根据过去猜接下来 | 时代五 |
| 训练集和测试集 | 考试题不能和练习题一样 | 时代五 |
| 过拟合 | 把练习题背下来，换道题就不会 | 时代五 |
| 准确率不是一切 | 少数类别错了，总分照样很高 | 时代五 |
| 数据的偏差 | 数据偏了，结果就偏 | 时代五 |
| 混淆矩阵（深入） | 错在哪一类，一张表看清 | 时代五 |

### 主干四 · 深度学习

| 技能 | 一句话 | 从哪学 |
|---|---|---|
| 神经元 | 把几个输入加权求和，超过门槛就亮 | 时代五 |
| 神经网络 | 一层层的神经元连起来 | 时代五 |
| 权重 | 网络学到的东西，就存在这些数字里 | 时代五 |
| 训练是调权重 | 猜错了，就把权重往对的方向调一点 | 时代五 |
| 自己学特征 | 不用人告诉它看什么，它自己找线索 | 时代五 |
| 看图的网络 | 先认边和角，再认形状，最后认物体 | 时代五 |
| 显卡和大数据 | 2012 年的突破，靠的是更多数据和更快的计算 | 时代五 |
| 强化学习 | 做对了给奖励，做错了扣分 | 时代五 |
| 自我对弈 | 自己和自己下，越下越强 | 时代五 |
| 策略和价值 | 下一步走哪，以及现在局面好不好 | 时代五 |
| 反向传播（深入） | 错误从后往前，一层层分给每个权重 | 时代五 |

### 主干五 · 生成式 AI

| 技能 | 一句话 | 从哪学 |
|---|---|---|
| 词元 | 文字先被切成一小块一小块 | 时代六 |
| 预测下一个词 | 一个词一个词往下接 | 时代六 |
| 注意力 | 理解一个词时，回头看看句子里哪些词最相关 | 时代六 |
| 预训练 | 先读海量文字，学会语言的规律 | 时代六 |
| 微调 | 再用少量例子，教它按某种方式回答 | 时代六 |
| 提示词 | 用自然语言告诉 AI 要做什么 | 时代六 |
| 幻觉 | 说得很像真的，但没有依据 | 时代六 |
| 核实 | 关键事实要查来源 | 时代六 |
| 检索增强 | 先查资料，再根据资料回答 | 时代六 |
| 工具调用 | AI 去用计算器、搜索、程序来完成任务 | 时代六 |
| 多模态 | 同时看图、听声音、读文字 | 时代六 |
| 温度和随机（深入） | 同一个问题，为什么每次回答不一样 | 时代六 |

### 主干六 · AI 与责任（含 REA 调查方法）

| 技能 | 一句话 | 从哪学 |
|---|---|---|
| 数据流向 | 软件把数据发到了哪里 | 委托：小账本 |
| 敏感权限 | 软件要了哪些不该要的能力 | 委托：手电筒 |
| 隐私 | 哪些信息能认出你是谁 | 委托：小账本 |
| 密钥不能写死 | 写进代码的钥匙，谁都能拿到 | 委托：天气小助手 |
| 后门 | 开发者留下的入口，别人也能用 | 委托：像素计算器 |
| 只在本地检查不安全 | 本机能改的东西，就挡不住人 | 委托：种田存档、像素计算器 |
| 看懂更新 | 对比版本，看说明里没写的变化 | 委托：便签 |
| 训练数据从哪来 | 用户同意了吗 | 终章 |
| 公平 | 对不同的人，结果是否一样可靠 | 时代五 |
| 版权 | 学来的东西能不能拿去用 | 时代六 |
| 可靠性 | AI 会错，关键决定要有人复核 | 时代三、时代六 |
| AI 安全 | 让 AI 做的事和人想要的一致 | 终章 |
| 人工复核 | 人留在决定的环节里 | 终章 |

## 4. 难度怎么分

| | 轻松 | 标准 | 硬核 |
|---|---|---|---|
| 讲法 | 生活里的比喻，不出术语 | 比喻 + 术语 | 术语 + 原理 + 数字和代码 |
| 例子 | 「把练习题背下来」 | 「过拟合：训练集准，测试集差」 | 看训练和测试两条曲线分开的位置 |
| 动手 | 拼规则、拖卡片 | 调参数、看结果 | 写几行代码（Python / JavaScript）训练一个小模型、算一次注意力 |
