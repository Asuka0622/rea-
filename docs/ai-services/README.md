# AI 选择与账号风险

核对日期：2026-10-14。

新手优先使用国模官方网页版；需要 AI 在项目里写代码时，优先选择国产工作台的国内站，并确认实际使用的是哪家模型服务。

使用 Codex / Claude 等海外 AI 前，请确认服务地区、账号授权和使用条款。不符合官方规则可能导致访问受限或账号停用（封号）。

工作台厂商与模型提供商是两回事。请使用自己的官方账号或正规 API；不购买来源不明的共享账号，不向第三方交出登录凭据。国产服务也有使用规则，不保证零风险。

## 官方资料

- [Codex 官方授权说明](https://learn.chatgpt.com/docs/auth)：Codex 支持 ChatGPT 账号登录和 API key 两种方式。使用前分别核对对应服务的地区、套餐和条款；API 地区清单不能直接替代 ChatGPT/Codex 的适用规则。
- [OpenAI API 支持地区](https://developers.openai.com/api/docs/supported-countries)：OpenAI API 官方说明：在名单外地区访问或提供访问，可能导致账号被限制或停用。
- [Claude 支持地区](https://www.anthropic.com/legal/supported-regions)：Claude.ai、Claude Code、API 及授权云渠道都受 Anthropic 的地区规则约束。
- [Claude 封禁与申诉说明](https://support.claude.com/en/articles/8241253-safeguards-warnings-and-appeals)：Claude 官方列出的封禁原因包括非支持地区注册、反复违反使用政策及违反服务条款。被误停用时使用官方申诉渠道。
- [Claude Code 授权边界](https://code.claude.com/docs/en/legal-and-compliance)：通过官方流程登录未修改的 Claude Code 有其受支持的使用方式。第三方应用不得收集或转发 Claude.ai 登录凭据；开发者调用模型应按官方要求使用 API 或支持的云服务。
- [Trae CN 模型说明](https://docs.trae.cn/ide_models)：国内站支持多种国模及自定义模型；具体可用模型和权限以当前应用显示为准。
- [CodeBuddy 官方入门](https://www.codebuddy.cn/docs/cli/quickstart)：推荐使用中国站官方入口；国内站与国际站的账号和模型选择需要分清。
- [Qoder CN 官方说明](https://help.aliyun.com/zh/lingma/)：阿里云现将 Qoder CN 和原通义灵码列为国内 AI 产品系列，包含编码工具、插件等形态。

推荐是针对本工作台学习场景的选择建议，不是免封号保证。OpenAI API 地区清单与 ChatGPT/Codex 服务规则应分别核对；本次没有为某个用户账号判断资格，也没有安装、登录或更换任何模型服务。
