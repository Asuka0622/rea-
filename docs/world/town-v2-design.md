# 比特镇新地图：分区、居民与互动设计

2026-10-18 · 可评审设计稿。依据 `docs/world-scale.md` 最新九区方案、`docs/art/asset-requirements.md`、`docs/art/npcs.md` 和当前委托渠道设计。本方案不代表地图、NPC寻路或全部对话已在游戏实现。

## 1. 玩起来是什么样

路米出事务所，先看见老周喂鸽子，听小石头沿街叫卖；旁边的居民楼只是有人生活，不亮任务标。玩家可以坐喷泉边、看报纸、敲邻居门，也可以直接去办案。阿桃会开店，小鹿会收杯子，阿康会遛狗；他们有自己的事，任务只是其中一部分。

保持现代小镇与AI教学定位：日常体验不每次都硬拐成知识问答。REA委托和AI时代主线仍按原有进度推进；不恢复暂停的汴京路线，不新增体力、饥饿、房租等负担。

## 2. 九区与连接

见 `town-v2-overview.svg`。九区构成3×3邻接布局、12条双向连接和四个局部环路；中心有四个出口，不是所有路线都必须经过中心。东北河堤到东侧街区的出口是桥头步道；北坡林出口是林间步道。

|北坡林|北区|河堤|
|---|---|---|
|住宅西区|中心广场|手艺西街|
|住宅东区|南岸|手艺东街|

每区2560×1440游戏空间，母版3840×2160，首批秋季晴天中午。镜头仍按640×360检查。一张图有16个视野面积，但实际可走地面、河面和山体不同，不能简单按16格填32件垃圾来冒充丰富。

### 像素与比例先统一

- 共同美术基础格1280×720：每格在游戏占2单位、在母版占3像素。关键轮廓按基础格绘制，交付母版与运行图来自同一网格；不把3840稿任意1.5倍采样后假装像素无损。
- 新NPC16×32原始小人建议映射32×64游戏单位。路米高清候选须按**可见人物**高度校准到同一档，而非只比较整帧尺寸。
- 成人可见身高约56–64游戏单位，儿童可略矮；门净高约72–88、净宽48–64，主路160–224、支路96–128、无障碍窄路最低64。特殊剧情大门可更高。
- 坐标、脚底和碰撞以游戏空间为准。JSON中的建筑框是布局草案，不是已测量美术；屋顶可遮挡范围另画，禁止直接整栋矩形都阻挡玩家。
- 现有“所有透明资源2倍密度”规则继续用于独立运行素材；地图母版3倍基础格单独标明，避免规范互相覆盖。

## 3. 建筑不等于任务

七个城镇区各规划3处主地点、2处日常建筑、3块预留地；两个探索区各最多1处未来服务小屋。共35处城镇建筑/摊位落点、21块未来用地、2处探索服务预留，合计58个落点。摊位不是都要画成大房子，预留地先是院子、菜圃和空铺，不能满街“待开放”按钮。

|分区|三处主地点|日常建筑，不默认挂任务|预留方向|
|---|---|---|---|
|中心|事务所、图书馆、档案馆|阿飞摊、广场居民楼|住宅/小服务店，不再塞更多主线大厅|
|住宅西|小林、阿哲、王奶奶住处|阿康家、邻居小院|居民住宅、合住院落|
|住宅东|朵朵家、小雨家、快递站|小满家、邻居住宅|住宅、社区服务|
|手艺西|面包店、公共作坊、鞋铺|陶艺住宅、裁缝店|手艺铺、店住一体|
|手艺东|咖啡店、游戏厅、模型工作室|画室门廊、乐手住宅|创作工作室、小店|
|北区|办公楼、钟楼、工具铺|修表摊、工匠住宅|维修铺、工作室|
|南岸|驿站、诊所、灯塔|渔家小院、茶水铺|住宅、小型码头服务|
|河堤|自然步道、水位尺、旧船|至多一处避雨服务小屋|不建商业街|
|北坡林|林间步道、观鸟、岩石样本|至多一处护林小屋|不开成采矿经营区|

### 四种门，四种回应

1. **开放场所**：进店/借阅/休息；有日常用途，即使没有委托也不是空房间。
2. **私人住宅**：敲门后屋内回应，允许“先不打扰”；无许可不直接闯入。大部分住宅无需独立室内地图。
3. **临街门廊/摊位**：在外面聊天、查看展示；不假装每个铺面都能进。
4. **预留地/封闭建筑**：外观和一句合理生活说明即可；不开不可完成的任务，不反复弹“即将开放”。

任务关联是可选字段。建筑负责“这里是什么、能怎么互动”，任务系统负责“当前发生什么”；更换租户或支线不必换地图。

## 4. 路线与玩家节奏

- 主路从四边出口接到区内地标，旁路形成小环；建筑院落有出入口，不设必须绕整区的长栅栏。
- 出口宽160，落点离边界48并向内走出触发带，区间切换设置短暂再触发锁；不能来回弹图。相邻出口坐标按JSON互相核对。
- 72单位/秒步行、约115冲刺时，2560宽直穿约36/22秒；这仅是直线估计，真实路长必须灰盒实测。入口到主要目的地建议步行8–18秒，超过25秒考虑改路线。
- 熟悉路线可由手账选择已去过地标快捷到达，非任务进度门槛；具体是否启用保留设置。不能靠重复捡叶子补偿无聊跑图。
- 公共路不被店铺关门、普通NPC或剧情队列堵住。雨天和夜晚仍能找到委托入口；NPC本人不在时，门牌说明去向并提供稍后联系。
- 每个可达视野至少有一处可辨识的去向、景物变化或互动；2处有内容的互动为目标。只有在可达范围内、能实际回应的门/物件才计数，未开放按钮、远处NPC和反复拾取不计。自然留白不被强行填满。

## 5. 可互动物品

`town-v2-plan.json` 每区列了4个代表互动，共36种场景实例，**不是已经覆盖每一屏的完整布点表**。更多点位应在三块灰盒试玩后补，避免批量复制低价值物件。

分为阅读、观察、使用、坐下、敲门、轻触、遭遇七类。交互半径48–72游戏单位；玩家先走到可达站位再操作。地标默认不亮问号，靠近出现一句简短名称和操作提示，手账可开启辅助高亮。

|用途|例子|反馈与边界|
|---|---|---|
|日常|长椅、菜单、门铃、鞋铺样鞋|坐下、读菜单、聊天；不强行转成考试|
|观察|水位尺、旧报纸、窗台、修补旧船|看日期、变化与细节；数字和可读文字由程序显示|
|小玩具|皮球、模型展示、原创试玩机|短动画或30秒试玩，有立即退出；不会堵住道路|
|学习入口|工具样件、预约本、快递屏|明确“这是模拟样本”；入口与日常外观分开，不能把点一下算知识达标|
|剧情来源|小雨门口、公告、传闻物件|先记录发现条件，再确认接取；碰到一次不每帧重弹|

每件物品记录 id、所在区、锚点、碰撞、交互站位、动作、文本、条件、冷却、是否一次性、是否保存。居民信件、包裹和电脑不给玩家随便读取；需要案件授权时用当前自制样本。

收集只是可选装饰：普通落叶可观察不捡；少量独特纪念物可记手账。同一物件点击次数不作为任务/知识完成证据。

## 6. NPC是居民，任务身份可选

现有12位常驻NPC沿用原 id 与形象，新增建筑为他们提供真实活动落点；不要再次批量造12套人。细节与60句对白见 `town-v2-dialogue.md`，行为模板与日程见JSON。

|NPC|日常行为|位置变化与交互|
|---|---|---|
|阿桃|开烤箱、理订单、收摊|面包店门口/台后，午休可在街边遇到|
|老魏|听表、夹放大镜、整理零件|钟楼下修表摊，雨天缩到棚内|
|小满|看书、犹豫写笔记、放学回家|上午标为上学不在镇上，放学在住宅东活动；学校不凭空作为已建场景|
|阿飞|擦盘、整理箱、招呼客人|广场摊位，雨天收箱，不能每天随机换区|
|小鹿|擦杯、贴便签、收桌|咖啡店与门前座位|
|大壮|扫码、搬轻箱、腾柜|快递站内外，不站在玩家取件站位|
|老周|喂鸽、抖面包袋、坐长椅|广场树荫到喷泉，雨天去檐下|
|阿康|遛狗、看提醒、蹲下系牵引绳|住宅西小环路；狗不独立乱跑卡门|
|小石头|送报、叫卖、核对日期|中心—住宅西—住宅东—南岸—中心固定环线；不必串遍九区|
|老陈|擦灯罩、看潮位、夜间巡灯|南岸灯塔与码头，恶劣天气留近岸|
|小铃|对表、登记误差、帮师傅收工具|北区工具铺与修表摊|
|老宋|量鞋、补底、观察路人鞋印|鞋铺门内/门前，午休在檐下|

前六位的拟议新支线仍是设计，不会因对白写好就自动成为可接任务。老陈、小铃、老宋保留已做的三份迁移练习，知识门槛与独立完成判定不变。小林、阿哲、小雨、朵朵、王奶奶、老秦、周姐、铁叔另按原案件角色接入，不把他们误算成全新居民。

### 日程与状态机

行为：`idle → walk → work/rest → talk → resume`；另有 `shelter`、`home`、`off-map`。进入对话暂停这个NPC的移动，结束后恢复当时日程；剧情演出可以临时覆盖日程，但不得复制出第二个同名NPC。

- 设计建议一轮游戏日48分钟，独立模拟时钟；现有界面时钟与钟楼11:58的剧情状态分开。48分钟是待实现的模拟参数，不声称当前时钟已经如此运行。
- 开菜单、查证据、做实验时暂停模拟推进；读长文本不会错过居民。手动改时间后重算日程，不跳过任务条件。
- 夜间闭店不锁主线：已接案件可通过门口联系进入样本现场，或在事务所手账“继续调查”；日常服务可以休息。
- 屏幕内真实走路；屏幕外根据日程计算所在节点，不逐帧模拟九区。重新进入画面从合理入口出现，不在玩家眼前瞬移。
- 先避玩家、再避其他NPC。卡住2秒尝试局部绕行，5秒退到安全点；只有在视野外才允许重新落点。NPC不占满桥和门。
- 雨天优先去本区屋檐或自己的室内，不能瞬间集体穿墙。雷雨无需所有人都多一套专属动画，先复用待机/走路。
- 重要NPC缺席时“去向提示”优先于催玩家等待，不把追赶NPC当教学难度。

## 7. 对话不是随机念一句

选择优先级：当前交互的剧情/委托状态 → 未读首次见面 → 玩家点选的话题 → 天气时段/近期世界变化 → 普通闲聊。结案感谢只在对应完成标记存在时出现；拟议支线完成句暂不启用。

靠近只出现一条不抢焦点的招呼，每位30秒内不重复；按E/点击再正式对话。除原来一次性剧情遭遇外，不把路过变成无法跳过的弹窗。被拒绝的委托至少等玩家再次主动选“说正事”才展开。

正式话题：`随便聊聊 / 镇上的事 / 说正事（有来源时） / 你要去哪儿 / 先走了`。每次最多显示3–4项，任务不相关时不放空按钮。不同角色有口气差异：王奶奶叫路米“闺女”，小满嘴硬，老宋简短，不人人都用教科书句式。

示例：

- 王奶奶没见过路米：「闺女，帮我瞧瞧，这灯怎么还要看我的通讯录？」→“先聊聊/看看问题/先不接”。
- 已接但未完成：「东西我留着呢，不急，你慢慢查。」→“继续调查/聊点别的/告辞”。
- 完成后：「灯只管亮就成，别的它可不能乱问。」之后恢复买菜、晒太阳的日常，不永久复读感谢。
- 小鹿雨天、没有任务：「窗边今天能听见雨打棚顶。」→“坐一会儿/看看菜单/先走了”，不强塞索引教学。

传闻是发现来源，不等于自动接受。`board / talk / encounter` 三种渠道保留；新对象来源可扩展为 `object:<id>`，但要先实现并验证规则，不仅在数据里写一个字符串。取消、拒绝、退出实验都不增加知识等级。

对话数据字段：id、speaker、conditions、priority、lines、choices、effects、cooldown、once。条件只用白名单规则；不执行文本表达式。随机闲聊采用有种子的轮换袋，短期不重句；正式任务状态不随机。

## 8. 代码接入边界

当前 `game-regions.js` 仍是五区960×540，`world-scale.js` 推荐常量仍1440×810，镇上 `npcEls()` 仍画圆点。本设计文件不直接替换这些运行配置，以免在没有新底图/碰撞前毁掉可玩版本。

建议分离：

|数据/模块|职责|
|---|---|
|区域数据|边界、双向出口、出生点、地标、路网、预留地|
|建筑数据|独立id、地块、门、可进入性、营业规则、住户；不以case id作为唯一建筑id|
|NPC目录|形象、称呼、家、工作场所、日程、话题与可选任务关联|
|NPC模拟|时钟、状态机、寻路、避让、离屏位置；不负责知识奖励|
|互动/对白规则|条件选择、冷却、选项与事件，展示层只渲染|
|任务进度|发现/接受/完成及证据；只有真实完成回调能结案|
|存档|版本、已见话题、世界物件状态、位置、剧情事件；派生路径不存|

地图迁移保留原case/quest id与存档key，不把“改住址”当重置任务：`homes`按建筑分为西/东，`craft`按店铺分西/东；工具铺到north，驿站和诊所到south，老秦到center.archive。旧`real-stories`入口保留到案例馆内容的别名，不误用成老秦的新案件id。

旧坐标不能全局乘2.667：旧五区拆九区且建筑移位。读旧存档时按建筑门口映射，只有区名无有效建筑时落本区安全点；玩家在案件室内则原样恢复案件。先做迁移预演，再切换存档版本。

性能预算目标：同屏8–12个活动NPC、附近最多16个；超出的背景人可简化待机，离屏只更新日程。按区域懒加载地图和精灵，不一次解码全部九张3840母版；运行贴图导出后检查内存（单张3840×2160 RGBA未压缩约31.6MiB，九张约285MiB，不含GPU副本）。普通闲聊先本地编写，不要求每次联网调用大模型。

## 9. 美术要交什么

先中心一张灰盒，再按同一比例画正式母版；参考 `town-v2-center-blockout.svg`。房子既要能辨用途，也要有居民生活痕迹：晾衣、盆栽、修补、信箱，而非每户一个发光任务标。

每区分别交：底层地面与固定地形、建筑主体、可遮挡屋顶/树冠前景、可调查物独立透明图、天气水面/灯光层、碰撞与通行标注、门口/互动站位/出口坐标、普通/私人/预留建筑清单。旧960图只参考色调，不拉伸。

不把NPC、问号、调查物、文字和任务提示烘焙进底图。已有喷泉、旗、鱼、涟漪、小船、木屑、晾衣等动画优先复用；先定位与验比例，不重复出图。12位NPC现有精灵先接入；有明确动作需要且复用不够时才补画。

九区本身不包含AI六时代地图；钟楼是独立旅行入口，不把历史时代硬塞到现代街区道路。

## 10. 分阶段交付和验收

1. **灰盒三块**：中心＋住宅西＋手艺西，先复用旧图作参考不冒充完稿。验证比例、走路、两条日常环线、普通敲门和NPC不挡路。
2. **生活样板**：先老周、阿康、阿桃、小铃四位，覆盖静坐、遛狗、营业、委托；实现天气避雨和对话恢复。阿桃拟议任务暂不启用。
3. **九区连接**：接余六区与12位常驻角色、既有案件角色，保留迁移兼容；所有预留地只作景观。
4. **正式美术替换**：中心优先，逐区重建碰撞和遮挡；一次一张地图验收，不批量换完再找比例问题。
5. **支线扩展**：只在样本、玩法和完成判定齐备后开启拟议支线；普通居民无需人人转为任务发布者。

验收包括：12条边双向可走且不回弹；新旧档可恢复；所有必要委托昼夜可继续；雨天有合理去向；私人屋敲门不乱开案件；对白不重复抢焦点、完成句不提前；NPC不穿墙/堵桥/可见瞬移；每类物件可达且能退出；人物与门桌大小一致；每个被宣称开放的室内确有内容；自然区保留留白又不让玩家迷路。
