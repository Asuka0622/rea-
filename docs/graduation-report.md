# 预告版结业报告与小镇生活旁注

2026-10-19。预告版结尾签发「见习侦探结业报告」，沿用事务所纸质档案与印章，受评人是玩家扮演的路米，由事务所档案室签发、小克作生活旁注；评语参考实际行为。报告不是医学或人格诊断。办案成绩与趣味习惯分开，不因求助、发呆或夜间活动扣资格。

## 玩家能看到什么

- 调查习惯、提示使用、出错与对质重试、完成推理与实验的评语。
- 「小镇里的你」最多三条生活旁注。比如发呆观察员、比特镇夜猫子、赶路小旋风、转角巡逻员。
- 每条趣味旁注可展开依据；末尾可核对案件记录。
- 保存为中文 TXT；结尾签发后，在任务日志重看。签发后的报告保存原稿，不被之后闲逛改写。
- 重开剧情时清除旧签发报告与小镇行为统计；已有案件记录按原有游戏存档规则保留，报告明确说是「可用委托过程记录」，不宣称它们都是新一轮产生的。

## 趣味规则

只在预告版户外、页面可见且获得焦点、玩家可以自由操作时统计。对白、菜单、地图、案件、特写、剧情演出、后台不计。切出窗口会中断连续静止；超过一秒的延迟帧不补计。移动看位置的实际变化，顶墙按方向不算跑动。仅保存总秒数、次数与分区 ID，不保存输入日志与坐标轨迹。

|旁注|最低记录条件|
|---|---|
|发呆观察员|连续静止45秒；前15秒不计入累计发呆时长，30秒算一个静止段|
|比特镇夜猫子|游戏内夜间移动20秒，且占移动时间至少一半；剧情跳时本身不计|
|赶在早餐前的侦探|游戏内黎明移动20秒，且占移动时间至少一半|
|赶路小旋风|实际跑动20秒，且占移动时间至少六成|
|转角巡逻员|实际进入4个不同分区|
|雨中散步派|地图明确提供 rain/rainy/storm 状态且户外移动15秒；当前天气系统未接入时不会出现这条|

规则在 `public/detective-habits.js`，接入 `game-shell.js` 的实际移动循环。按发呆、夜间、黎明、跑动、分区、雨中顺序取最多三条，暂不随机，方便复核。旁注描述已观察到的行为，不把静止直接归因为走神、把夜间游戏归因为现实晚睡。

## 记录与兼容

- `rea-demo-habits-v1`：本机预告版趣味行为汇总，每10秒及窗口切出/离开时写入。
- `rea-case-observations-v1`：实际结案时独立存储过程摘要，避免修改案件文案导致版本化检查点失效。练习 drill 不覆盖正式委托摘要。
- `rea-demo-graduation-v1`：签发后的报告。
- 旧存档优先用已有完整结案检查点补读。缺记录则明确留白，不把缺失解释为玩家未调查。镇上交谈和彩蛋注明本机累计，不冒称当轮行为。
- 全部在本地计算，无模型请求、无外发遥测；浏览器存储不可用时仍可当场阅读、下载。

## 验证入口

`/graduation-review.html` 是明确标注虚构记录的独立预览，可切换四种报告；不读取、不修改游戏存档。真实游戏仍只在结尾/取得徽章后的任务日志签发和重看。

`node --test test/graduation-report.test.mjs` 覆盖行为差异、后台与菜单排除、夜间比例、连续静止、存档与导出、无记录留白等。全量回归结果见 PROGRESS.md。

2026-10-19 身份修正：玩家＝路米，报告不得把路米写成玩家的导师或旁观者。旧签发报告按原有案件摘要、行为统计与签发时间重排文案，保留真实记录，不要求重新游玩。

## 路米的证件照（2026-10-19）

- 序章设置完体验偏好与基础后，先显示「这次，你就是路米」，说明调查居民、互动键和任务日志，再进入拍照登记。旧存档未拍过照时可补拍，不清除案件进度。
- 复用已有 lumi-normal / happy / thinking / surprised 头像，提供自然、开心、思考、惊讶四种表情。选中有勾选标记。拍照后定格，可重拍；只有点击「确认归档」才保存。表情不影响成绩。
- 角色照片单独存储于 `rea-lumi-id-photo-v1`，记录 version、face、takenAt，图片地址只由受控表情生成。`public/detective-id.js` 管理资料与拍照组件。
- 任务日志可重拍或补拍。取消不覆盖旧照片；归档后刷新仍保留选择，已有结业报告只更新照片，不重算案件成绩与签发时间。
- 报告标题右侧放证件照，结业标记移到标题下。真正结尾如仍无照片，会先补拍再显示报告。缺照片的旧示例显示待补拍，不冒称玩家已选择自然表情。
- `/graduation-review.html` 的「试拍路米证件照」演示同一个组件，在示例页只修改内存，绝不写真实角色照片。四种示例的前三种演示当前试拍照片，旧存档示例仍保留空白。
- 图文导出目前仍是原有 TXT，文本注明证件照表情；游戏报告中显示图片。没有加入整页图片导出。
- 验证：真实游戏介绍与拍照入口、示例页拍照/重拍/确认到报告图片已实测；390px窄屏照片保持右上角。照片存档、非法数据、旧报告升级等新增4项测试通过。

## 游玩纪念与羊皮卷（2026-10-19）

报告同时保留前台游玩时长、已到达世界/引入场景、探索地区、委托数量与星级、成就总数及已解锁名称、徽章和学会的知识。成就从现有运行状态取快照，只列真实解锁项，不提前展示未解锁的隐藏成就。伦敦仅在实际结尾画面播放后标为剧情引入，不等于完成伦敦地图。

`public/graduation-game-record.js` 管前台时长与世界记录，存档key为 `rea-demo-play-record-v1`。包含读对白、菜单和案件操作，切后台不计，暂停后的长帧不补算。重开剧情会重置该计时；成就/案件等沿用现有本机累计规则，报告里标明口径。报告签发后这些快照不会被继续闲逛或重拍证件照改写。

报告副本版本升至4；旧签发报告没有游戏统计时留白，不拿后来进度填成当年的成绩。日期、办案记录、证件照与趣味行为保持兼容。TXT包含游戏统计、成就名称与知识名称。
