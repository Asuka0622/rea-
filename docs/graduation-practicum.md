# 结业实操：从「看别人查」到「自己查一次」

> 2026-10-18。回答一个必须诚实回答的问题：**小白打完序章，能不能自己逆向想要的软件？**
> 答案是不能。序章给的是认知（知道从哪下手、怎么验证），不是手感（没摸过真工具）。
> 这一关就是补手感的桥：demo 的最后一关，**用工作台真跑一次，写出五问**。

## 0. 它解决什么

| 序章结束时 | 加了这一关之后 |
|---|---|
| 见过六个样本，全是游戏里的模拟终端 | 用**真的工作台**跑过一个软件，看过真的报告 |
| 知道「要验证」 | 亲手选了一种验证手段，并说得出预期结果 |
| 能跟着推理板走 | 自己从零写出一份五问报告，别人能复核 |

一句话：**它不教新知识，它证明你会用**。

## 1. 什么时候出现

- 前置：六份委托全部结案（`prologue-quests.js` 的七份，含加密猫）。
- 地点：事务所，路米把工作台推过来（不新开地图）。

## 2. 流程（5 步，约 12 分钟）

1. **选样本**：三个内置样本之一（见第 4 节），或「用我自己的软件」。
2. **跑一遍**：真的打开工作台、真的分析（游戏外完成，游戏里只记录状态）。
3. **答题**：五个问题，每题从候选里勾选 + 可选一句结论。
4. **判分**：`public/report-score.js` 当场给每题分数与理由。
5. **结算**：过了 8 分发「见习侦探」徽章 + **毕业清单**（第 6 节）；没过可以改完重交，不扣分。

## 3. 五问与判分

| 问题 | 要写成什么 | 满分 |
|---|---|---|
| 它要了哪些能力 | 权限 / 系统能力 / 外部设备 | 2 |
| 数据发到了哪里 | 域名、接口路径、上报时机 | 2 |
| 密钥藏在哪里 | 代码里 / 配置里 / 服务器上 | 2 |
| 有没有隐藏入口 | 后门、调试通道、开机自启 | 2 |
| 你会怎么验证 | 抓包 / 沙盒 / 改副本 / 下断点 + 预期看到什么 | 2 |

判分规则（实现见 `report-score.js`，测试见 `report-score.test.mjs`）：

- **2 分**：主项全选、没有误选
- **1 分**：漏了主项，或混进一个不该选的
- **0 分**：选错、空着、或「本来有却说没有」
- **「没有」也要写出来**：确实没有隐藏入口时，必须显式选「没有」，空着按 0 分算——和加密猫那关同一个道理

**8 分通过，9 分优秀。**

## 4. 样本

内置三个，覆盖三种典型形态（都需要能被工作台扫出可验证痕迹）：

| 样本 | 形态 | 关键点在教什么 |
|---|---|---|
| 小工具 · 剪贴板看板 | Electron / JS | 数据流向 + 定时器（和小林的案子同型，但换个壳） |
| 手电筒 · 改版 | APK | 权限与声明不匹配 + 开机自启 |
| 旧日记 · 存档 | 自定义存档 | 编码 vs 校验（不加密，但不改校验就读不进去） |

「用我自己的软件」：不自动判分，只做结构检查（五问都写了吗、有没有落到具体行），给鼓励性评语，并提示「这份报告可以用来看懂你自己的软件」。

## 5. 反馈要具体

每题都给一句 reason（`漏了：contacts`、`写了「没有」，可这里其实有`），总评分三档：

- 优秀：五问都落到证据上
- 通过：能独立写出五问，差的是没落到具体那一行
- 未过：`还差 N 分，先补最空的那一问：___`

## 6. 毕业清单（带走的东西）

| 组 | 内容 |
|---|---|
| 工具 | 工作台、JADX（APK）、Ghidra（.so/.exe）、Wireshark / mitmproxy |
| 练习 | ①自己的小工具跑五问 ②一个 APK 只做「权限 vs 功能」 ③同一软件两个版本做对比 |
| 坑 | base64 不是加密；搜不到不等于没做（加壳/混淆）；只静态不下结论 |
| 边界 | 只查自己的或有权研究的软件；绕过授权、外挂、破解不是这份清单的目的 |

## 7. 和现有系统的接法

- **不进行动点预算**：真实工具没有回合限制，硬套会变成折磨。这一关只按报告质量评。
- **可以无限改**：教学要纠错；分数只记最好的一次。
- **徽章**：通过后发「见习侦探」，和现有成就系统同一套。
- **和加密猫的关系**：加密猫教「证据不足也是结论」，结业实操考「你会不会落证据」，顺序上加密猫在前。

## 9. 验收

- 找 3 个没玩过 demo 的人，在只用工作台的情况下写五问：**至少 2 人 ≥ 8 分**。
- 自选样本的人，至少能说清「下一步该装什么工具」。

## 10. 风险

- **答案可以被抄**：内置样本固定，攻略一搜就有。缓解：自选样本那一栏鼓励真做，且内置样本的判断只作为门槛，不作为成就。
- **12 分钟可能不够**：真跑一次工作台（含准备环境）常常超过。宁可让它慢，也别做成假操作。
