# 比特镇预告版 · 音乐与音效需求

2026-10-19，按当前代码和完整序章流程盘点。**这是待制作、待接入的需求单；本轮不生成音频，不改播放逻辑。** 可执行清单见 [audio-cues.csv](audio-cues.csv)。

## 1. 当前已经有什么

- `public/game-sound.js` 使用 Web Audio 合成14种短音效：对白字音、门、脚步、正确、错误、解锁、点击、翻页、打字、盖章、提示哔声、线索发现、反驳、紧张提示。有音效总开关并保存选择；首次点击/按键后启用音频。
- 现有这些是可用的程序声音，不能记成14份已经制作好的音频素材。接下来优先补缺，不强制全部重做。
- `public/rhythm-game.js` 独立合成节拍器与低音伴奏，按音频时钟提前调度；当前关卡包含92与104 BPM，自有暂停和静音。**不能把它简单替换为一条自由播放的BGM。** 它与主音效开关目前也不是统一的音量总线。
- 当前运行目录没有独立的MP3/WAV/OGG背景音乐文件，也没有普通场景的BGM切换系统。拍照、卷轴展开、天气和剧情细节仍有缺声位置。

## 2. 范围与风格

预告版覆盖：路米身份介绍与证件照 → 小镇自由探索 → 六份REA委托分三幕 → 事务所线索墙 → 23:58守夜 → 钟楼真相、居民争论、小克的问题 → 时光机 → 1843伦敦街道与沙龙引入 → 见习侦探结业报告。

路米就是玩家；小克是搭档。音乐从「轻松、好奇」走向「发现异常、追问真相」，结尾重新回到温暖，保留一点未完待续。小镇以柔和芯片音色、木质敲击和少量钢琴为主，伦敦换成克制的钢琴/拨弦/小编制弦乐，仍能听出相同的原创主题动机。不用持续人声唱词，不让配乐替代线索声音或盖过阅读。

P0＝Demo首批；P1＝下一轮润色；P2＝正式版或玩法确认后再做。不要为每个NPC、每栋房子、六个案件各画一套声景；优先复用主题和声部变化。

## 3. 首批8组背景音乐

以下时长是制作目标，不是已经交付的文件时长；均需要可长时间循环的主体。BPM只是创作范围，普通BGM不参与判定。

|---|---|---|---|
|bgm-town-day / P0|白天小镇、身份介绍；明亮而好奇|75～110秒，约82～96 BPM；主旋律留白|进入白天自由探索；进室内/案件/演出后淡出。同一城镇分区切换不重头播|
|bgm-town-night / P0|傍晚/夜间闲逛；安静、有秘密但不恐怖|90～120秒，约64～78 BPM；复用小镇主题|游戏内时段进入夜间；守夜剧情开始时让给专用配乐，不按现实电脑时间切换|

**第一首试做建议：**先交小镇白天曲，确认音色和主题，再做夜晚、事务所与结业变奏。这个顺序只决定制作先后，不代表现在已经开工。

## 4. 5段短音乐

## 6. 交互音效：14种保留，8组补缺

保留 `game-sound.js` 的14种声音作为默认：`blip / door / step / right / wrong / unlock / click / page / key / stamp / beep / clue / objection / tension`。以后可替换更合适的素材，但不要边播文件边再触发同名合成声。

|新增ID / 优先级|位置与触发|制作要求|
|---|---|---|
|sfx-camera / P0|证件照点击“拍照”|0.15～0.4秒，轻快快门；切换表情只用已有click。确认归档可用现有stamp，不另加旋律|
|sfx-scroll-open / P0|羊皮卷报告真正展开|0.6～1.2秒纸张展开；不滚动页面就反复摩擦，也不盖过结业短音乐|
|sfx-clue-wall / P0|卡片钉上线索墙、红线连接|0.1～0.4秒/次，纸片/图钉；同一串卡片限频。红线轻拉声可选，不与已有stamp三重叠加|
|sfx-heavy-lock / P0|铁叔插钥匙、锁舌退开、开钟楼门|拆成钥匙/锁扣/门轴三小段；方便适配实际动作时机。不要一段长音写死三步节奏|
|sfx-tower-anomaly / P0|灯闪、指针抖一下又停住、机器异常|拆成短电流与机械卡止声；不是修复成功的钟声，不惊吓式突然爆响|
|sfx-watch / P0|怀表亮起、机关转动、时光机回应|2～3个短事件声；和time-jump短音乐分工，音乐负责情绪、音效负责动作|
|sfx-npc-life / P2|坐长椅、修表、揉面等已确认的生活动作|按真正接入的动作补短样本，随机间隔和距离衰减；不因每帧更新重复播放|
|sfx-step-surfaces / P2|草地、石板、木地板、室内|每种至少3个轻微变体；只有真实位移才响，顶墙与暂停不响。当前先保留合成step|

环境与生活音效应与地图可见对象相符，不凭空安排人群、交通或大雨。读代码/输入搜索时的键音保留较轻，连续输入要限频。

## 7. 小游戏如何用音乐

- 六份正式案件以**当前实际挂载的lab/stages**为准：小林网络实验、朵朵存档、小雨计算器、阿哲管道、周姐版本时间线、王奶奶权限实验。不能只看game.lab.kind就把所有候选小游戏当成主流程。
- 管道、卡牌/对质、权限塔防、经营等可复用调查曲或其低密度声部；错误、尝试、提示有轻音效，但不限时的题不能配持续倒计时压迫声。
- 节奏小游戏目前另有独立试玩/挂载入口。进入时停普通BGM，保留它自己的节拍与判定音；未来正式曲按当前谱面92/104 BPM分段制作，交精确拍点、预备拍、起始偏移和暂停恢复方案。**先保留现有合成伴奏，本轮8组BGM不包括替换音游曲。**
- 胜利/失败画面用短提示后回到安静状态；重试不能叠上上一轮音乐，离开电脑和切后台要暂停音游。

## 8. 播放规则与程序待办

这些是接入要求，不是已实现的音乐系统：

1. 主音乐同一时刻只有一首。优先级：音游专用音频 > 剧情演出 > 结业报告 > 案件 > 室内 > 小镇；短音乐另外调度，先压低原BGM，结束恢复。
2. 普通对白沿用所在场景曲，不每句台词切歌。守夜、钟楼揭示、小克提问等在脚本事件处切换/降配，玩家读得慢也能循环等候。
3. 普通换曲0.6～1.5秒交叉淡化；进门、换区与案件菜单不能多次创建播放器。照片表情选择不切换背景音乐。
4. 提供音乐/音效/环境声音量与总静音；音游独立音频也必须服从总静音。后台暂停或静音，返回由明确状态恢复，首次用户操作前不强行自动播放。
5. 静音和设备没有音频时仍能完成所有玩法。线索、警告、成就和节拍判定仍有视觉反馈；不只靠音色区分正确与错误。
6. 不把UI等待秒数当配乐结束点，不让页面滚动触发快门/卷轴声。跳过演出、关闭报告、离开案件都要清理当前声音。
7. 现有 `game-sound.js` 的总开关和 `rhythm-game.js` 的独立静音需要统一调度；现在没有接好，不在需求表里写“已完成”。

## 9. 交付、命名与验收

- 建议路径：`public/audio/music/`、`stingers/`、`ambience/`、`sfx/`；本次清单只规划这些路径，不建立假音频文件。
- 音乐母版WAV，建议48kHz/24bit；另交运行压缩版。最终OGG/MP3组合以目标浏览器实测选择，不能把MP3编码留白当无缝循环。
- 每组附：ID、版本、用途、实际时长、BPM/拍号（有节拍才填）、循环起止采样点、是否有前奏/尾奏、来源与授权说明。普通循环先交完整混音；守夜/钟楼等需要渐进演出的再交必要声部，不要求所有曲目过度拆轨。
- 无缝循环连续听3轮，无明显断点/爆音；不同曲目音量接近、不削波，耳机和手机小音箱都检查。对白字音、调查反馈和音游判定保持可辨。
- 桌面与手机各核对：首次进入、夜间切换、进出房间、案件/对质、暂停/切后台、重复打开报告、连续多成就、演出跳过、总静音。旧声音和新文件不能双响。
- 首轮按3首试样推进：小镇白天 → 调查 → 结业；确认风格与音量后再完成其余场景。

## 11. 部署交接约定（由部署方补充，2026-10-19）

清单里的路径是**运行目录**，不是交付目录。请按下面三条走，否则素材会直接进打包产物：

|用途|目录|是否入库|
|---|---|---|
|待审试样|`docs/audio/review/<id>-review.wav`|不入库（已加 `.gitignore`）|
|通过后母版|`docs/audio/master/<id>.wav`|不进打包产物|
|运行压缩版|`public/audio/{music,stingers,ambience,sfx}/<id>.ogg|mp3`|入库、进部署|

1. **先待审再入库**：试样放 `docs/audio/review/`，文件名 `<id>-review.wav`。审批通过后才改名去掉 `-review` 进正式目录。首批那件 `bgm-town-day-review.wav` 原本落在 `public/audio/music/`（23.4 MB，会被打进桌面包），已由部署方归位到 `docs/audio/review/`。
2. **每个音频附同名 sidecar JSON**：`id / version / use / seconds / bpm / timeSignature / loopStartSample / loopEndSample / hasIntro / hasTail / source / license`。没有节拍的填 `null`。循环点必须是 48 kHz 下的整数采样值，不能用秒数。
3. **有尾奏的曲子单独说明**：循环版与尾奏版要么分两个文件，要么在元数据里给出精确循环点，由播放器按采样点循环。默认当"必须能无缝循环"处理。

查接线状态：`npm run wiring`（美术 + 音频两条一起跑）。音频那条以 `audio-cues.csv` 为唯一清单源，报已接线 / 已交付待接 / 待审试样 / 待制作 / 孤儿五档，孤儿必须为 0。
