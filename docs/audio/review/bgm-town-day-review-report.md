## 3. 两个必须返修的问题

### 3.1 尾部淡出，不能直接无缝循环

需求文档第 9 节要求"无缝循环连续听 3 轮，无明显断点/爆音"。现在这份是**带尾奏收束的完整混音**：

- 结尾最后 50 ms 只剩 -45 dB，接近静音；
- 播放器的循环点若直接接回开头，会先经历约 0.65 秒的塌陷，再从 -12 dB 突然起声；
- 接缝落差约 **32 dB**，听感是"音乐散掉一下再重新进来"，而不是循环。

**请音频组二选一：**
1. 另交"循环版"：去掉尾奏淡出，让结尾与开头在采样级连续（首尾波形衔接），母版另存 `bgm-town-day-loop.wav`；
2. 或沿用现版本，但在 sidecar 元数据里给出精确循环点：`loopStartSample` / `loopEndSample`（48 kHz 下的整数采样值）与 `hasTail: true`，由播放器按采样点循环、尾奏不参与。

### 3.2 响度偏热、动态被压平

- Integrated **-15.0 LUFS** 是流媒体单曲的做法，不是游戏 BGM 的做法。游戏里这条曲子要长期循环，还要托住对白字音、环境声和判定音。
- **LRA 只有 1.0 LU**，几乎整首一个响度。文档第 3 节要的是"明亮而好奇、主旋律留白"，现在听不出起伏，长时间循环容易疲劳。

**建议母版目标：**
- Integrated **-20 ～ -23 LUFS**；
- True peak **≤ -6 dBFS**（给音效和语音留 headroom，避免叠加后逼近 0）；
- LRA 放到 **4 ～ 8 LU**，让段落之间有呼吸。
