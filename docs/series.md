# 比特镇系列：各部游戏的路线

> 2026-10-16 定系列；2026-10-19 重写成「各部路线说明」。原来「一部游戏装下整个计算机学科」的设计留档在 `docs/archive/concept-all-subjects.md`，全学科的知识盘点在 `docs/archive/curriculum-all-subjects.md`。
> 第一部的后续（正式版迁移到 Godot 4、NPC 接本地小模型、CG 过场、引擎渲染）见 `docs/roadmap.md`；后面几部同样在正式版的引擎上做。

## 1. 为什么是系列

- **讲得深**：一部只讲一门，就能从起点讲到今天，覆盖完整的知识链；一部塞六门，每门只剩四五个知识点。
- **故事紧**：一部一个主题，时代、人物、谜题都围着同一个问题转。
- **能接着做**：每一部自成一体，做完就能发布；后面的部复用同一套系统和比特镇。

## 2. 每一部的样子（共同的骨架）

- **比特镇是大本营**：四季、天气、昼夜，每一部都从这里出发。镇上的居民跨部延续，每部有自己的新角色。
- **一个镇上的谜开场**：先用侦探委托或小镇事件把这一部的问题摆出来（第一部是「钟楼为什么停在 11:58」）。
- **钟楼时光机**：回到这一门学科诞生的年代，沿着历史一路走回今天。每部有自己的一组时代。
- **路米和小克**：玩家扮演路米（可选女生或男生）。小克在第一部里就是路米的搭档，结局后留下来，从第二部起一直跟着；它会说错、会说「我不确定」——这也是系列一以贯之的一课：**拿证据说话，核实了再信**。
- **主线讲基础，传说任务讲应用**（`docs/quest-tiers.md`）；同一知识点在不同阶段换不同玩法（`docs/knowledge-depth.md`）。

## 3. 各部路线（顺序和名字暂定，只有第一部已定）

### 第一部 · 人工智能（在做）
- **谜**：钟楼停在 11:58，镇上六个软件每晚 23:58 往钟楼送数据。
- **序章**：路米的侦探事务所，六个委托分三幕，用逆向分析查清真相（就是现在的预告版）。
- **时代**：1843 伦敦（巴贝奇、爱达）→ 1950 曼彻斯特 / 1956 达特茅斯（图灵）→ 1970 年代斯坦福（专家系统）→ 1997 纽约（深蓝）→ 2012–16 多伦多与首尔（深度学习、AlphaGo）→ 2017 至今（生成式 AI）→ 回到现在，钟楼走到 12:00。
- 设计：`docs/concept.md`、`docs/story.md`、`docs/story-prologue.md`、`docs/curriculum.md`。

### 第二部 · 计算机是怎么来的（计算史与计算机基础）
- **问题**：一台电脑，里面到底是什么？数字、文字、图片怎么变成 0 和 1？
- **时代线索**：算筹与《九章算术》→ 北宋汴京的水运仪象台（自己会守时的机器）→ 帕斯卡、莱布尼茨的机械计算与二进制 → 差分机 → 1940 年代的电子计算机。
- **知识主干**：位值制和进制、二进制、输入 / 处理 / 存储 / 输出、内存与硬盘（断电就忘 / 一直记得）、时钟和节拍。
- **从第一部旧主线搬来的设计**（2026-10-19 从网页版删掉，设计留着）：
  - 原第一章「打开钟楼」：铁叔、门上的 8 盏二进制灯、零件归类（输入处理存储输出）、两个抽屉（内存与硬盘）。
  - 原「古代中国」一站：州桥边柳娘子的茶铺（摆算筹算账）、韩公廉和苏颂的水运仪象台（调天衡、稳住节拍）、算学斋、书坊。详细设计见 `docs/archive/era-china.md`。
  - 汴京的美术需求在 `docs/art/prompts.md` 第五批（已暂停，画好的保留在美术工作树）。

### 第三部 · 编程（指令、程序与软件）
- **问题**：机器为什么能照着指令做事？怎么把一件事写清楚？
- **时代线索**：雅卡尔提花机的打孔卡 → 爱达的注释（第一段程序）→ 早期程序员与汇编 → 高级语言 → 开源。
- **知识主干**：顺序、循环、条件、变量、函数、调试、边界情况。
- **玩法储备**：指令卡积木（拼卡片让小人做事）；「写真代码」的题目按在线评测出题，玩家自选 Python、C、C++、JavaScript（原 `game-cards.js`、`game-code-runner.js`，2026-10-19 随旧主线删掉，代码在 git 历史里）。

### 第四部 · 网络与互联网
- **问题**：一条消息怎么从这台电脑走到那台电脑？
- **时代线索**：烽火与驿站 → 电报 → ARPANET → 万维网（CERN）→ 移动互联网。
- **知识主干**：地址、分包与路由、协议、域名、加密传输、网页是怎么来的。
- **原设想**：第一部旧设计里的「1960–90 年代 · 连接世界」一站。

### 第五部 · 密码与安全
- **问题**：怎么让秘密只被该看的人看到？
- **时代线索**：凯撒密码 → 中世纪的口令与城门 → 恩尼格玛与破译 → 公钥密码 → 现代的账号与隐私。
- **知识主干**：加密与解密、密钥、哈希、身份验证、常见攻击和防御。
- **原设想**：第一部旧设计里的「中世纪欧洲 · 城堡与密码」「1940 年代 · 破译」两站。侦探事务所的逆向分析在这一部讲得更深（第一部只教到基础）。
