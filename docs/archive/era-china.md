## 1. 时间、地点和钩子

- **时间**：北宋元祐年间，约 1088 年。
- **地点**：东京开封府（汴京）。
- **钩子**：比特镇钟楼的时光机第一次启动，把路米和玩家送到了九百多年前的汴京。这里也有一座钟楼正在建造，就是苏颂和韩公廉的**水运仪象台**。时光机的「节拍」坏了，要回家，得先弄懂这座钟楼是怎么做到准时的。

**为什么从这里开始**：
- 水运仪象台是「钟楼的祖先」，正好接上比特镇停摆钟楼的主线。
- 它用一套叫「天衡」的擒纵机构，让水力驱动的轮子一格一格、稳稳地走，这就是今天电脑里「时钟信号」的老祖宗。
- 同一时期，沈括在《梦溪笔谈》里记下了毕昇的活字印刷；算筹和《九章算术》是当时人人要学的算学。数、算法、编码、存储，电脑的根都能在这里找到。

## 2. 史实依据

| 素材 | 【史实】 | 在游戏里教什么 |
|---|---|---|
| **算筹** | 用小竹棍摆数。《孙子算经》说「凡算之法，先识其位，一纵十横，百立千僵」：个位竖摆，十位横摆，纵横交替；空位表示零 | **位值制**：同一个符号，放在不同的位置，代表不同的大小。二进制也是这个道理，只是每位只有 0 和 1 |
| **《九章算术》的更相减损术** | 约分时，「以少减多，更相减损，求其等也」：两个数，用大的减小的，反复做，直到两个数相等，这个数就是公约数 | **算法**：步骤明确、一定会停下来、得出答案。再和「辗转相除」比一比，就知道同一个问题有快有慢的方法 |
| **毕昇的活字印刷** | 《梦溪笔谈》记载：庆历年间毕昇用胶泥刻字；常用字如「之」「也」每字做二十多个；平时按韵分类，贴上纸签，存在木格里；准备两块铁板，一块在印，另一块同时排字，轮流使用 | **可复用的零件**（一次刻好、反复使用）、**索引和查找**（按韵分格，像字典的目录）、**流水线**（两块板轮流，不让人闲着） |
| **烽燧的「品约」** | 汉代边塞有《塞上烽火品约》（居延汉简），规定敌人多少、从哪里来，就点几堆火、举什么信号。宋代边防也一直在用烽燧 | **编码**：事先约好的规则，把消息变成信号；信号越少越快，但要能区分清楚 |
| **水运仪象台** | 苏颂主持、韩公廉设计计算，元祐三年开始建造，元祐七年（1092 年）完成。三层：顶上是观测用的浑仪，中层是演示星空的浑象，下层的报时木人按时出来敲钟击鼓。靠一套「天衡」擒纵机构控制枢轮，使它一格一格匀速转动 | **时钟信号**：电脑里的 CPU 也靠一个稳定的「节拍」，每拍做一步；**自动控制**：不用人看着，机器自己按时运转 |
| **急递铺**（支线） | 宋代的递铺接力传送公文，一站接一站 | **接力转发**：网络里的数据也是一站一站转发过去的（为 1960–90 年代的网络打伏笔） |
| **交子**（支线） | 北宋在四川由官府发行纸币交子，用复杂的印版和暗记防伪 | **防伪**：怎么证明这张纸是真的（为中世纪的安全打伏笔） |

## 4. 主线（4 章，约 5 个核心知识点）

### 第一章 · 落在州桥边
- 时光机一阵乱转，路米和你落在汴河州桥边。阿砚把你们当成外地来的书生。
- 柳娘子的茶铺来了一大桌客人，账算不过来。**小游戏「摆算筹」**：用竹棍摆出数、做加法和进位。
- 学会：**位值制**（同一个符号在不同的位置代表不同的大小；对照比特镇学过的二进制）。

### 第二章 · 算学斋的约分题
- 阿砚说城北有座钟楼正在建，你们要找的人在那里。去之前得先过算学斋这一关：韩公廉手下的算学生出了一道约分题。
- **小游戏「更相减损」**：两堆算筹，按规则一步步相减，直到相等。
- 硬核难度加题：再用辗转相除做一遍，数一数谁的步数少。
- 学会：**算法**（明确的步骤，一定会停）、**有快有慢的算法**。

### 第三章 · 书坊赶印
- 程掌柜要赶印一批工地要用的算表，人手不够。
- **小游戏「活字排版」**：按韵分格的字盘里找字、排成一行。常用字有很多个，生僻字没有就要现刻，很花时间。
- 支线：「两块铁板」，一块印一块排，体验流水线比一块板快多少。
- 学会：**可复用的零件**、**索引和查找**。

### 第四章 · 天衡的节拍（高潮）
- 算表印好送到工地，水运仪象台却怎么也走不稳：枢轮时快时慢。同一时间，城外传来烽火急报，工地的木料运不进来。
- **小游戏「烽火品约」**：按约定把消息编成几堆火、几道烟，传给下一座烽燧；再把收到的信号解读出来。
- **小游戏「天衡」**：调整受水壶和秤杆的配重，让枢轮一格一格、间隔均匀地转动，跟上节拍。
- 结局：水运仪象台的报时木人第一次准时敲响。苏颂向你们道谢；路米发现时光机的节拍也跟着稳了下来，下一个时代亮了起来。
- 学会：**编码**、**时钟信号**。

**回到比特镇对照**：铁叔把比特镇钟楼的齿轮和天衡放在一起比，告诉你今天的 CPU 也是靠一个每秒几十亿次的「节拍」工作的。白医生的诊所顺势开了「系统」的小课（通关后自由模式）。

## 4.5 测试版本只做这一小段

测试版本每个时代只走一小段（约 15 分钟、2 个知识点、2 个小游戏）。古代中国的测试段：

1. **落在州桥边**（主线一的缩短版）：时光机乱转，落在州桥边，阿砚带路；在柳娘子的茶铺**摆算筹**算账 → 学会**位值制**。
2. **天衡的节拍**（主线四的缩短版）：阿砚说城北的钟楼走不稳，带你去工地；韩公廉请你调**天衡**的配重，让枢轮匀速转动 → 学会**时钟信号**。报时木人第一次准时敲响，时光机的节拍也稳了，下一个时代亮起，回到比特镇。

**三档难度的差别**：

| | 轻松 | 标准 | 硬核 |
|---|---|---|---|
| 摆算筹 | 只摆两位数，竖摆横摆有图示，直接点格子放 | 摆三四位数和带空位（零）的数，做一次进位加法 | 不给图示，按「一纵十横，百立千僵」的口诀自己摆；加一道多次进位的加法 |
| 讲位值制 | 「同一根小棍，放在左边一格就大十倍」 | 位值制、十进制，对照二进制每位大两倍 | 再讲为什么要纵横交替（防止相邻两位看混），以及空位到后来才用「○」表示 |
| 调天衡 | 一个配重，拖到刚好的位置 | 两个参数：配重和水流，要同时调准 | 三个参数，还要算出一个时辰枢轮要走多少格 |
| 讲时钟信号 | 「钟楼靠一下一下的节拍走路」 | 时钟信号：CPU 每一拍做一步，主频就是一秒多少拍 | 再讲主频和功耗的关系，看一眼真实 CPU 的主频数字 |
| 深入知识点（只在硬核） | — | — | **反馈控制**：天衡怎么靠水斗的重量自己控制节奏 |

测试版需要的场景：汴京地图、茶铺、水运仪象台内部；角色：阿砚、路米时代装、柳娘子、韩公廉（苏颂在结尾露一面即可）。
主线二（更相减损）、主线三（活字）、烽火品约留到完整版。

## 7. 地图与场景

**汴京地图**（一张 960 × 540 分区图，可扩成两张）：
- 汴河自西向东流过，州桥横跨河上；河边是茶铺、酒楼、码头和货船。
- 御街从南向北；街两旁是书坊、钱庄、药铺、算学斋。
- 城北一片工地：搭着脚手架的水运仪象台，三层木构，顶上是浑仪。
- 城墙一角：递铺和远处山头的烽燧。
- 季节：**暮春**（柳絮、桃花），和比特镇的秋天形成对比。
