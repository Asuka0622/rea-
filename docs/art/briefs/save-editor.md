# 美术需求：种田存档 · 存档编辑器（朵朵）

> 2026-10-18，小克写。玩法改版：不再是一步接一步的流水线，而是一个存档编辑器——存档内容可以直接改，旁边有 Base64 还原/编码、校验码计算器、「让游戏读档」，目标只有一个：读档后金币是 9999。盐要自己在 save.js 里搜。最后两道「换你当开发者」的选择题：单机要不要防、联网该怎么防。
> **现在全部用代码画的占位**，美术交图后由小克接入。请合进美术总单（`docs/art/art-team-master-2026-10-18.md`）的小游戏部分。代码在 `public/case-labs.js` 的 `mountSave`。
> 序章里这个实验嵌在朵朵房间的电脑终端里（绿屏风格），单独打开时是纸面风格，图标请两种底色上都看得清。
