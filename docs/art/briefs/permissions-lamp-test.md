# 美术需求：开灯用得上吗 · 沙盒里的开灯实验（王奶奶）

> 2026-10-19，小克写。王奶奶案现在是能走进去的解谜关卡（客厅背景和八件道具已经交付并接上了），沙盒是两关：① 开灯用得上吗 ② 守住手机（塔防，见 `tower-defense-v2.md`）；结案后再找王奶奶，还有一关复刻练习「奶奶牌手电筒」（见 `manage-grandma-flashlight.md`）。
> 第一关不再是「看权限名二选一」，而是实验：勾掉几项权限，按一下开灯，看灯亮不亮、行为监视器记下什么。每条判断都要有一次实验撑腰；一次拿掉好几项能省实验，灯不亮就得拆开排查。
> **现在全部用代码画的占位**。代码在 `public/case-labs.js` 的 `mountPermissions`，规则在 `public/permission-lab.js`。
