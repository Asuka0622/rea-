# 美术需求：权限的代价 · 奶奶牌手电筒（王奶奶）

> 2026-10-18，小克写。玩法改版，**并且换了剧情位置**：原来是玩家经营一家（像小光那样的）手电筒公司、开局权限全开、往下关。可玩家在王奶奶一案里是查小光的那一方，不该转头去当它。现在这关是这个案子的「复刻练习」（案例结尾本来就写着「想一想，一个只要闪光灯权限的手电筒应该怎么设计」）：王奶奶说「孩子，你给我做一个干净的吧」，玩家亲手做「奶奶牌手电筒」，从 1.0 发到 1.8。
> 每版桌上来一张提案——找上门的是案子里查出来的 QuickAds 业务员、收小光数据的那家数据公司，提需求的是王奶奶和她的老姐妹们——玩家拍板、发版、结账。右边是自己写的权限清单（每项标「说得清 / 说不清」）和「王奶奶装的时候看到的弹窗」。1.3、1.6、1.8 发完商店审核。
> **现在全部用代码画的占位**，美术交图后由小克接入。请合进美术总单（`docs/art/art-team-master-2026-10-18.md`）的小游戏部分。代码在 `public/manage-game.js`，规则在 `public/manage-engine.js`。
