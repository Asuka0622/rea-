# 美术需求：行为监视器 · 抓现行（小林的小账本）

> 2026-10-18，小克写。玩法改版：不再照清单一步步做，而是四件「要证明的事」，玩家自己在沙盒里做实验，再从监视器里挑一条记录钉上去当证据；可以往剪贴板里放一个独一无二的「诱饵」追踪数据去向；时间不会自己快跑，要点「快进 30 秒」。
> **现在全部用代码画的占位**（文字按钮、色块、边框），美术交图后由小克接入。请合进美术总单（`docs/art/art-team-master-2026-10-18.md`）的小游戏部分。代码在 `public/case-labs.js` 的 `mountNetwork`。
> 这个实验在序章里嵌在小林房间那台电脑的终端里（绿屏风格），单独打开时是纸面风格。图标请两种底色上都看得清。
