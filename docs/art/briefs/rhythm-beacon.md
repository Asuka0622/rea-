# 美术需求：定时上报 · 信标检测（小林的小账本）

> 2026-10-18，小克写。玩法改版：原来是两条轨道、颜色就告诉你答案；现在只有一条轨道，所有请求长得一模一样，玩家要靠**节奏**分辨——程序偷偷的自动上传像节拍器一样准时，你自己点的同步时有时无。D 放行、F 拦截。分三段：「听规律」→「更密」→「它学聪明了」（上传加了随机抖动，节奏靠不住，这时请求上会显示目的地，改看去哪儿）。
> **现在全部用代码画的占位**，美术交图后由小克接入。请合进美术总单（`docs/art/art-team-master-2026-10-18.md`）的小游戏部分。代码在 `public/rhythm-game.js`（谱面在 `public/rhythm-engine.js` 的 `makeBeaconChart`）。
> 关键约束：前两段**音符不能用颜色或形状暗示是哪一种**，否则玩法就没了。两种请求必须用同一张图。
