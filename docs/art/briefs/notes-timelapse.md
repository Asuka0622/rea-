# 美术需求：快进一天 · 延时实验（周姐的随手便签）

> 2026-10-19，小克写。周姐案现在是能走进去的解谜关卡（办公室背景和七件道具已经交付并接上了），沙盒是两关：① 审清单（扫雷，另一个会话做的）② 快进一天。
> 第二关在沙盒里装 1.0 或 1.1，时钟从早上 9:00 开始，玩家自己快进；行为监视器记下它做的事。四件事要各钉一条记录当证据：1.1 会自己截屏、截图攒到 23:58 一起送去悄悄统计、1.1 删掉了导出、对照组 1.0 一整天什么都不发。
> **现在全部用代码画的占位**，沿用行为监视器（`network-monitor.md`）的样式。代码在 `public/timelapse-game.js`，规则在 `public/timelapse-lab.js`。
