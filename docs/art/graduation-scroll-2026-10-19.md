# 美术交付单：路米的羊皮卷结业报告

日期：2026-10-19。用户明确要求：保留游玩时长、探索世界/地区、成就等游戏记录；结业报告使用羊皮卷；需要的新素材由美术组完成。本单是待制作需求，不是已交付或已验收声明。沿用大地图优先的现有排期，本功能素材可独立认领。

## 已确定的内容与角色

玩家本人就是薄荷青发的路米。序章先认识路米，再选自然/开心/思考/惊讶表情拍证件照。结尾卷轴右上角使用玩家确认的证件照；签发方为比特镇侦探事务所档案室，小克只作生活旁注。不要把路米画成给另一个玩家颁证的导师。小克如出现仍是指定橙色像素蟹，不改成机器人。

报告从上到下：卷首装饰 → 事务所/日期 → 标题与右上证件照、结业标记 → 游玩纪念（时长、世界、地区、委托、星级、成就、知识、徽章）→ 办案评语 → 趣味旁注 → 签发/记录依据 → 卷尾。正文长度随玩家记录变化，不是一张固定高度海报。

当前功能预览：`http://127.0.0.1:7321/graduation-review.html`，仅本机可访问。程序里目前是羊皮卷结构占位，不是正式美术交付；证件照暂复用4张现有 `public/art/faces/lumi-*.webp`。接收方拿不到本机预览时按本单结构制作，不能将截图中的虚构数据画进图。

## 切片与正文安全区

- 母版宽1536；两侧最外64px用于纸边，正文建议留在x=112..1424。卷首/尾中间接合处使用与body相同的纸色，避免细黑缝。
- 桌面正文约600～700 CSS px宽，手机内容可小到约300px；卷首/尾等比缩放，body按宽度缩放后纵向重复。不能把整卷纵向硬拉长，也不以裁掉正文适配。
- 标题、日期、称呼、数字、成就名称/锁定状态、技能列表、说明、照片框、按钮全部由程序绘制。四表情共用纯色浅青照相底；美术交透明人像，由程序铺底。
- 图片的阴影与纸张厚度保持克制；不在文字区画强烈褶皱、暗斑、透视倾斜或发光特效。卷首尾不要用真实木头横杆占掉大面积视野。
- 卷轴不做强制滚动演出，打开可用程序轻微展开；减少动态效果时立即显示。不要为本轮额外画一整套卷动序列帧。

## 现有程序接口与接入责任

- `public/graduation-report.css` 已有 `.graduation-report[data-scroll-art="approved"]` 卷首/主体/卷尾三切片接口。正式素材复核后由接入方启用标记；当前不请求不存在的图。
- 印章交付后由接入方加装饰图，资格文字仍是可读DOM。当前程序尚未接入正式印章。
- `public/detective-id.js` 控制四表情与选择存档。新证件照交付后由接入方更新受控映射；现在仍指向旧的已交付头像，不依赖新图完成流程。
- 如果最终尺寸/路径需调整，先更新本单与接入映射再交付，禁止只改文件名不通知程序。
- 提交只包含自己制作的资产/说明，避免覆盖并行代码与旧头像。提供8张PNG的尺寸/alpha/用途清单和一张横向对照预览；对照图是验收附件，不作为额外运行素材。

## 验收

1. 8个运行PNG齐全，尺寸和alpha符合表格；无水印、文字、假透明底。
2. 三张卷轴片拼成长短两份报告，body重复3次和8次均无横向接缝、纹理跳变或底色闪烁。
3. 正文与右上照片不重叠；长成就名、零成就、旧记录缺失都能显示。
4. 手机390px和桌面740px内容宽核对，头像能看清，纸边不吞正文；动态数据均可选中/复制，不烘焙成图。
5. 四种证件照切换时脸的位置不跳动；预览选表情→拍照→重拍→确认→报告必须使用确认的那张图。
6. 图交付后只标「待接入/待验收」，接入方完成上述实测才标通过。
