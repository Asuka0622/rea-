## 0. 先看这里

**场景风格更新**：地图、建筑、室内、道具与小动物统一采用用户提供的像素场景参考方向：繁茂的自然环境、层叠树冠与岩石、清楚的方块像素簇、浓郁明暗、蓝绿色水面、赭黄色土路、红金色季节植被。采用高位 3/4 俯视，画面细节丰富但留出可走空间。不要照搬任何现成游戏、角色或场景。**只有对话头像用二次元立绘**，放在像素风木框对话框里。

**全局季节、天气与时段**：当前暂定四季为春、夏、秋、冬；天气为晴天、雨天、雪天；时段为早晨、中午、傍晚夕阳、夜晚。地图与对应室内必须共享同一个状态：植物/落叶/积雪、地面湿痕、窗外景色、阳光方向、室内窗光与灯具亮度都要吻合。文件名或交付清单标明 `season-weather-time`。季节通过季节版底图表达；时段与天气可用可叠加的光照/天气效果复用，但会改变室内物件或地面细节的地方需要单独变体。**当前首批基准状态只有 `autumn-clear-noon`；不要把它描述成已覆盖全部 48 种组合。**

**细节一致性**：晴天不画雨伞、雨滴或明显积水；雨天要有湿润路面、窗上雨痕，室内可出现收起的雨伞/雨衣；雪天要有积雪、雪靴或暖炉等合理细节。春季有新芽和花苞，夏季枝叶浓密，秋季有黄红叶与落叶，冬季有裸枝和积雪。早晨光线偏柔且低，中午窗光明亮、以日光为主，装饰灯仅留低亮暖光；傍晚使用金色夕照和较长阴影，夜晚以冷色窗外环境和室内实际灯源照明。设备类火光（如锻炉）要符合房间是否正在工作。室内摆件、植物、窗外景色、地面与光源必须和当前地图状态一致；禁止只换整体色调却保留不合时令的细节。

**三条规则**
1. 角色和场景全部原创。提示词里**不要写任何现有游戏、动漫、角色或画师的名字**（包括星露谷），只描述想要的样子。
2. 同一类图用同一段"统一风格词"。第一张满意后，把它当参考图（或固定种子），保证整套画风一致。
3. 像素要整齐：每个像素格大小一致，没有模糊和抗锯齿。AI 出的"像素画"常常格子不齐，出图后用图片工具按**最近邻**缩小到下面写的"原始尺寸"，交付原始尺寸的文件。

**两种画法**：
- **对话头像是二次元立绘**：高清插画，界面自动裁出头肩、缩小放进木框。
- **场景和场景里的小人是像素画**，界面放大 3 倍显示（1 个画面像素 = 3 个屏幕像素）。场景和小人必须按同一个像素大小来画，小人站进场景里才协调；所以小人很小（16×32），只表现发型、发色、衣服颜色这些大特征。

**交付**：PNG，文件名全小写、用短横线，放进指定文件夹。人物头像和图标要**透明背景**。

**已有的东西**：`public/art/portraits/` 里已有路米 4 个表情、小林 3 个表情的二次元立绘，已经在用了。其余角色请保持同样的画风；画小人时也按这些立绘的人物设计（发型、发色、服装、配饰）。

English：
> Japanese indie game dialogue portrait, anime illustration, bust-up from the chest, clean lineart, cel shading with soft shadows, bright warm colors, expressive face, centered, transparent background, high quality

负面词：
> 文字、水印、签名、多余的手指、畸形的手、模糊、写实照片、3D 渲染、像素风、暴露服装、背景杂物 ／ text, watermark, signature, extra fingers, deformed hands, blurry, photorealistic, 3d render, pixel art, revealing clothes, cluttered background

### 规格

- 竖版 3:4，和已有的路米、小林一样大（约 1086 × 1448），**透明背景 PNG**。
- **头放在画面上方居中**：界面会从顶部裁一个正方形（宽度的约 82%）作头像，所以头顶到肩膀要落在上方这块正方形里。
- 同一角色的所有表情：同一套衣服、同一角度、头的位置和大小一致，只换表情和手势。
- 文件名：`<角色>-<表情>.png`，放进 `public/art/portraits/`。之后运行 `python -I scripts/prepare-portraits.py` 生成网页用的小图（小克来做也可以）。

| 表情 | 后缀 | 什么时候出现 | 补充描述 |
|---|---|---|---|
| 普通 | normal | 平时说话 | 平静微笑，看向前方 |

## G. 场景里的小人（16 × 32，透明背景）

> ✅ **路米的做法就是标准做法**：直接交**高清的原图精灵表**（像你画的路米那张：透明背景，一行一个动作，从上到下依次是待机 2 帧、向下走 4 帧、向上走 4 帧、侧面走 4 帧、说话 2 帧，同一行的帧从左到右排）。**不要自己缩小到 16×32**，缩小会糊。把原图交给小克，小克用 `scripts/import-sprite-sheet.py` 切帧、对齐脚底、生成游戏用的精灵表，界面会平滑缩放显示，并按走路方向切换正面、背面、侧面。

和场景同一种像素粗细，站姿正面或略侧，脚踩在画面底边。每个角色一张，文件名 `sprite-<角色>.png`（角色前缀同 A：lumi、kobayashi、azhe、xiaoyu、duoduo、zhoujie、grandma）。

中文：
> 温馨农场生活类像素游戏里的小人角色，像素画，原始尺寸 16×32 像素，全身站立，正面略侧身，大头小身体的可爱比例，清晰的方形像素点，无抗锯齿，有限调色板（约 12 色），深色像素描边，透明背景

## J. 人物动画（逐帧，每帧 16 × 32）

**用逐帧动画，不要用骨骼动画。** 骨骼动画会把图片旋转、拉伸，像素格会被打乱、变糊；像素游戏（包括星露谷）都是一帧一帧画的。

每个角色一张**精灵图**（所有帧排成网格的一张图），加一个同名的 JSON 说明文件：

- 文件：`anim-<角色>.png` 和 `anim-<角色>.json`
- 每帧 16 × 32，透明背景，帧与帧之间不留空隙；每一行是一个动作，从左到右是这个动作的各帧
- 角色的脚在每一帧里都站在同一条线上（帧底部），身体位置不要左右漂

**标准人物格式**：共8列×6行动作表；第1行待机2帧（第2帧眨眼），第2–5行分别是向下、向上、向左、向右走，每行8帧，每帧75ms；第6行说话2帧。四个方向独立绘制，左右脚交替、手臂自然反向摆动。8帧步态按以下节奏循环：A腿领步且步幅最大，步幅逐帧收小，双脚经过身体下方并换重心；随后B腿领步、步幅重新变大，再逐帧收小并再次换重心。第1帧和第5帧须清楚呈现相反腿领步：第4帧脚收至身体下方，第5帧新领步腿要明显迈出、步幅重新打开，不能只交换脚的遮挡或让角色整体平移。每个相邻帧都要顺着摆动脚轨迹和身体重心连续变化，第8帧回第1帧也要自然衔接，不能突然换脚、跳位或重复脚姿。手臂与腿反向配合：A腿迈出时对侧手臂向前摆，换重心后B腿迈出时另一侧手臂向前摆，所以第1帧和第5帧的摆臂方向也必须交换，手的位置逐帧变化。原有手持物固定在同一只手，形状和朝向稳定，随手臂自然移动。视角须匹配游戏地图的高位3/4俯视镜头并沿用当前角色视角；旧精灵表仍按原有帧数播放，重制完成后再同步更新JSON。

| 行 | 动作 | 帧数 | 说明 |
|---|---|---|---|
| 1 | idle（待机） | 2 | 轻轻呼吸或眨眼 |
| 2 | walk-down（向下走） | 8 | 朝向镜头走；最大步幅、收步、换重心、反腿最大步幅、收步、换重心 |
| 3 | walk-up（向上走） | 8 | 背对镜头走；可辨认两腿交替支撑与迈步 |
| 4 | walk-left（向左走） | 8 | 朝左走；独立绘制，脸朝左，第1/5帧换领步脚 |
| 5 | walk-right（向右走） | 8 | 朝右走；独立绘制，脸朝右，第1/5帧换领步脚 |
| 6 | talk（说话） | 2 | 张嘴、手势（可选） |

JSON 格式（每个动作的行号、帧数、每帧时长）：

```json
{
  "frame": [16, 32],
  "animations": {
    "idle":      { "row": 0, "frames": 2, "ms": 500 },
    "walk-down": { "row": 1, "frames": 8, "ms": 75 },
    "walk-up":   { "row": 2, "frames": 8, "ms": 75 },
    "walk-left": { "row": 3, "frames": 8, "ms": 75 },
    "walk-right":{ "row": 4, "frames": 8, "ms": 75 },
    "talk":      { "row": 5, "frames": 2, "ms": 250 }
  }
}
```

提示词在 G 的小人提示词后面加上：
> 精灵图，同一个角色的多帧动画排成网格，每帧16×32像素，共8列×6行：第一行待机2帧，第二行向下走8帧，第三行向上走8帧，第四行向左走8帧，第五行向右走8帧，第六行说话2帧；四个方向各自独立绘制、每帧75ms。每方向八帧步幅顺序是：A腿领步且最大步幅、步幅逐渐收小、双脚经过身体下方并换重心、B腿领步且步幅重新变大、再次逐渐收小、再次换重心并循环；第1和第5帧明确是相反腿领步。手臂自然反向摆动，手的位置逐帧改变；原有手持物固定在同一只手、外形稳定并跟随手臂；不能只上下起伏或滑行，不能八帧都由同一只脚领步。每个方向8帧连续不同，循环首尾自然衔接；帧之间对齐、脚踩同一条底线，保留原角色外形。

## 真实人物的画法（所有时代通用）

历史上的著名人物**可以参考原型来画**，让玩家一眼认出是谁：

- **已故的历史人物**（例如苏颂、韩公廉，以后的阿达·洛夫莱斯、巴贝奇、图灵、冯·诺依曼）：
  - 参考存世的画像、照片、雕像，保留最有辨识度的特征：脸型、发型、胡须、标志性的服饰或物件。比如图灵的短发和西装，阿达的维多利亚时代发型和裙装。
  - 再转成本游戏的风格：立绘是二次元，地图上是像素小人。要神似，但不是照片描摹。
  - 古代人物如果没有可靠的画像（宋代人物多半只有后世画的像），就按当时的服饰制度来画，参考后世的传统画像和塑像，在交付说明里写明参考了什么。
- **在世的人物**（例如互联网时代的一些发明者）：
  - 尽量不直接画本人，改成「致敬原型」的虚构角色，换名字、换外观，只保留职业和气质。
  - 必须出现本人时，只画成尊重、端正的形象，只放在档案、照片墙这类背景里，不做主要的对话角色。
- **所有真实人物都要画得尊重**：不夸张丑化，不搞笑变形，不加史实上没有的负面细节。表情以 normal / thinking / happy 为主，surprised 可以有，但不要做成滑稽的样子。
- 交付时在说明里写一句：参考了哪些画像或照片。
