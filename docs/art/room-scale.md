# 宿舍美术比例与栅格

行走坐标320×180，美术栅格640×360。一个逻辑单位对应2个美术像素。源素材保留，运行用派生图；透明边距不应计入物品实际大小。

| 项目 | 显示尺寸（逻辑单位） | 美术帧/图像像素 |
|---|---|---|
| 房间 | 320×180 | 640×360 |
| 路米 | 30×60，同一房间内恒定 | 64×128 |
| 小林 | 40×60 | 80×120 |
| 笔记本 | 28×20 | 56×40 |
| 手机 | 9×14 | 18×28 |
| 聊天平板 | 20×16 | 40×32 |
| 挂钟 | 18×18 | 36×36 |
| 路由器 | 22×14 | 44×28 |
| 说明纸 | 14×18 | 28×36 |
| 猫 | 24×21 | 48×42 |

背景与道具用最近邻采样，运行时避免混用平滑和像素采样。纸放在桌上；角色以脚底对齐行走位置。家具碰撞使用房间坐标，不能因换高清图而改变坐标单位。

路米已按小林参考重新生成减小头部、拉长身体的版本，接入小镇、普通室内和委托场景。统一动画导出64×128帧，透明128色；场景中的显示高度为60逻辑单位。不同场景仍需持续验收光照、视角与家具关系。
