# 宿舍美术比例与栅格

行走坐标 320×180。**房间背景按 1280×720 出运行版**（一个逻辑单位 4 个美术像素，正好等于 1280 窗口下一像素），用平滑采样缩放——背景是画出来的，用最近邻放大只会变成方块、看着糊。道具和角色按 2 倍像素密度出（640 栅格），继续用最近邻：它们是像素图，放大要保方块。源素材保留，运行用派生图；透明边距不应计入物品实际大小。

| 项目 | 显示尺寸（逻辑单位） | 美术帧/图像像素 |
|---|---|---|
| 房间背景 | 320×180 | 1280×720（平滑采样） |
| 路米 | 30×60，同一房间内恒定 | 64×128 |
| 小林 | 40×60 | 80×120 |
| 笔记本 | 28×20 | 56×40 |
| 手机 | 9×14 | 18×28 |
| 聊天平板 | 20×16 | 40×32 |
| 挂钟 | 18×18 | 36×36 |
| 路由器 | 22×14 | 44×28 |
| 说明纸 | 14×18 | 28×36 |
| 猫 | 24×21 | 48×42 |

背景用平滑采样（`.game-bg.art`），道具与角色用最近邻；两类不要混用同一张图。纸放在桌上；角色以脚底对齐行走位置。家具碰撞使用房间坐标，不能因换高清图而改变坐标单位。

## 三间委托房间的校准值（2026-10-17）

三间走同一套规则：`scene.art` 以 `case-room-` 开头即按校准房间渲染（`.calibrated-room`），人物 60 逻辑高、道具底边中点落在锚点上。

| 房间 | 可行走上边界 `top` | 地面起始 | 桌面约在 | 主要碰撞 |
|---|---|---|---|---|
| 小林的宿舍 `case-room-privacy-ledger` | 118 | y≈100 | y=76 | 床 `(242,104,78,52)` |
| 朵朵的阁楼 `case-room-farm-save` | 113 | y≈95 | y=72 | 床、床头柜、书桌椅、衣柜 |
| 小雨的房间 `case-room-calculator-eggs` | 123 | y≈105 | y=71 | 床、床头柜、书桌椅、书架 |

`top` 取「墙裙下沿 + 18」左右：人物站到最上面时头部仍在墙面内，走不出房间。碰撞判定用脚底 `y` 与半宽 9，站位须满足 `y ≥ 块底 + 5`，所以站在家具前的点一般取桌面下沿再往下 10–20 个单位。

路米已按小林参考重新生成减小头部、拉长身体的版本，接入小镇、普通室内和委托场景。统一动画导出64×128帧，透明128色；场景中的显示高度为60逻辑单位。不同场景仍需持续验收光照、视角与家具关系。
