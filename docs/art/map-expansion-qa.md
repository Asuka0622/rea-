## 2026-10-19 定版与审核结论（小克负责）

> 用户把九区的设计优化和素材审核交给小克决定。这一节以下的旧段落里，凡是和这里冲突的排法、出口、水系，以这里为准。依据：`docs/world/town-v2-plan.json`（数据）、`docs/world/town-v2-layout.png`（总览），规矩由 `test/town-plan.test.mjs` 自动检查。

**改了什么**

1. **九宫格统一成规划数据那一版**（北坡林·北区·河堤 / 老院巷·中心广场·面包街 / 菜园坊·南岸·咖啡街）。之前美术需求和本文档用的是左上、右上、左下对调的另一版，出口判定跟着错了。
2. **区名按特色起**：住宅西区 → 老院巷，住宅东区 → 菜园坊，手艺西街 → 面包街，手艺东街 → 咖啡街（id 不变）。
3. **补上剧情地点**：北区加「星博士的 AI 研究所」（小克的出处），中心加「广场公告屏」（滚动悄悄统计的广告）。北区的工匠住宅撤掉，给研究所让位（没有居民住那儿）。
4. **每区自己的布局**：原来七个城镇区用的是同一个「四角 + 右侧中间」模板。现在每区有自己的路网、地标和建筑落点——中心是喷泉广场，北区的钟楼在正北居中、从中心一路望得见，老院巷有一圈院落小巷，菜园坊围着共用菜园，面包街有后巷，咖啡街有画廊小广场，南岸的底边是海和码头。
5. **预留地按路网自动摆**：避开主路、支路、建筑、门前站位和地标，每块离路不超过 260，各区不再共用同一组坐标。
6. **水系简化**：全镇只剩一处接缝（中心溢水渠 → 南岸 → 入海，`x=1690`）；河堤的小河走地图外边界。
7. **只有钟楼是钟**：其他建筑不画钟面。

**出图方式（决定）**：不再整张生成分区底图。改成「地面瓦片（草、夯土、石板、水、岸线、坡）＋ 单独画的建筑和大件物件」，按 `town-v2-plan.json` 的坐标拼成整区。理由：整张生成既守不住像素画风也守不住精确布局（v3→v11 已经验证），而且拆不出验收要求的 base / front / shadow / emissive 分层和碰撞数据；拼法天然分层、天然对得上数据、九区画风一致。

## 风格与细节检查

- 用户反馈旧地图长时间观看不舒服，当前确认的修正方向是：保留原版精细像素画风、树量、建筑与构图；降低颜色饱和度但维持亮度；减少树叶和铺装的微小色块，不做大幅扁平化或删树。
- 路面按使用密度区分：中心广场、公共设施周围和手艺/商业街的人流主区域可采用简洁石板铺装；住宅区低流量巷道、河堤和林地小径保留夯土路。中心广场候选现有的石铺构图符合这个材质方向，但仍需按降低饱和度、合并大铺装块的标准复核；不能因此把全镇所有道路都铺石。
- 细节优化重点是树冠由碎叶点改为更大的像素色簇，石路由密集小砖缝改成稍大的铺装块；草地减少细碎噪点。颜色不应靠降低亮度来显得柔和。
- 2026-10-18 用户提供六张场景截图作统一画风参照，只参考截图中央游戏画面。昼间基图遵循 `art-team-master-2026-10-18.md` 第10节：灯笼/窗光关闭；基础色不烘焙强方向光与人物影子，树荫、静态阴影、发光层和遮光数据分层标注。当前构图候选未交这些分层，不能按光影验收通过。
- 石材按用途区分，不重复铺同一种灰色多面体：喷泉和建筑用规整切石，挡土处用错缝、不同尺寸的墙石，空地删无用途的孤石；不得占道路、门口或互动站位。
- 目前边界修正版仍有零散孤石、被围栏截断的短路、桥头接路不清等问题；这些属于路径逻辑缺陷，不能只靠接缝中心点通过来验收。
- 源文件和水路须人工逐边、逐路径检查。九格总览应再做一次相邻拼图，重点看中心—北区、中心—老院巷、中心—面包街、中心—南岸、南岸—河堤五组接缝。
