# 九区地图构图、路径与水系复核

更新：2026-10-18。依据 `asset-requirements.md` 九区布局逐张复核。当前地图图像均为 **1672×941 构图候选**，不能作为 3840×2160 母版或运行素材。

## 连接坐标与路线

- 九区按 `住宅东区 / 北区 / 北坡林`、`住宅西区 / 中心广场 / 手艺西街`、`河堤 / 南岸 / 手艺东街` 排列。
- 道路出口只在有相邻分区的边开放，且落在对应边中点：上/下边 `x=1280`，左/右边 `y=720`；通行净宽至少 96 游戏单位。未开放的边不能出现通向画外的路、桥、台阶或水流。
- 水口和路口分开定位，避免水流从铺装路面冒出：中心广场南侧水口约 `x=0.66W`，南岸北侧同坐标接入；南岸西侧水口约 `y=0.66H`，河堤东侧同坐标接入。水宽、岸线和护栏要在两区接缝处同宽、同位。
- 中心区水源仍未定：`town-v2-plan.json` 只列中心喷泉，没有记载右上岩泉或穿区溪流；`asset-requirements.md` 则要求中心南侧与南岸北侧有水口。不要再把右上岩泉当成既定设计。当前候选把水收在广场喷泉池内，未画水口，因此水系接缝仍未通过；正式出图前需在世界水系方案中明确上游来源、中心水道走向和南岸承接口，或修订水口要求。水不能从路面冒出，也不能与主路共用出口。
- 南岸溪流从北侧水口进入，向南后转西，从西边水口接入河堤；河堤内汇入有岸线的水潭，不再从其他区边缘出水。水路不能突然断头、贴着道路冒出，或在桥头没有可走路径。
- 所有道路支路须连上环路、建筑入口或有明确用途的地点；没有用途的短支路删除。门柱、灯柱、石块和围栏不能封住道路。石墙只放在确有挡土/分隔作用的位置，不在草地里散落奇怪孤石。

## 风格与细节检查

- 用户反馈旧地图长时间观看不舒服，当前确认的修正方向是：保留原版精细像素画风、树量、建筑与构图；降低颜色饱和度但维持亮度；减少树叶和铺装的微小色块，不做大幅扁平化或删树。
- 细节优化重点是树冠由碎叶点改为更大的像素色簇，石路由密集小砖缝改成稍大的铺装块；草地减少细碎噪点。颜色不应靠降低亮度来显得柔和。
- 2026-10-18 用户提供六张场景截图作统一画风参照，只参考截图中央游戏画面。昼间基图遵循 `art-team-master-2026-10-18.md` 第10节：灯笼/窗光关闭；基础色不烘焙强方向光与人物影子，树荫、静态阴影、发光层和遮光数据分层标注。当前构图候选未交这些分层，不能按光影验收通过。
- 石材按用途区分，不重复铺同一种灰色多面体：喷泉和建筑用规整切石，挡土处用错缝、不同尺寸的墙石，空地删无用途的孤石；不得占道路、门口或互动站位。
- 目前边界修正版仍有零散孤石、被围栏截断的短路、桥头接路不清等问题；这些属于路径逻辑缺陷，不能只靠接缝中心点通过来验收。
- 源文件和水路须人工逐边、逐路径检查。九格总览应再做一次相邻拼图，重点看中心—北区、中心—住宅西区、中心—手艺西街、中心—南岸、南岸—河堤五组接缝。
