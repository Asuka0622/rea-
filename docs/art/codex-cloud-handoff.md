## 风格约束

- 场景沿用比特镇现有的细腻像素环境：温暖木材、分层树冠、水面和秋季红金植被；默认场景基准为秋季晴天中午。
- 人物与小人沿用已有角色设计及像素精灵比例；同一角色的发型、服装、颜色、轮廓和阴影保持一致。
- 用户明确指定小克直接采用 Claude Code 的 Clawd 橙色像素蟹形象：方块橙色蟹身、深色方眼、短钳和小腿。小克已生成六表情头像、4×5 动画表和怀表图标；继续沿用现有文件，不改回白色机器人或薄荷青屏幕方向。
- 房间背景不烘焙独立调查物品；动态 UI、文字、数字、血条、提示和粒子交给代码。图像不生成伪中文或可读小字。
- 透明素材必须有真实 alpha。按清单的逻辑尺寸和 2 倍像素密度交付；动画逐帧同尺寸、基线一致，并附 JSON。
- 已有素材先核对与复用，不重复出图。最终运行文件放 `public/art/`；源图、候选和验收预览放 `docs/art/review/`；同步更新交付 CSV。
