# 新九区地图：美术与关卡交付说明

2026-10-18。依据用户要求扩展居民生活空间，具体方案见 [地图设计](../world/town-v2-design.md)、[九区总览](../world/town-v2-layout.png)（2026-10-19 定版；旧的总览和中心灰盒稿已作废删除） 和 [点位数据](../world/town-v2-plan.json)。本文件是新地图设计提案，不表示已制作或已验收；不替代已有素材返工清单。

## 首张先做中心，先验布局再出完稿

- 游戏空间2560×1440、母版3840×2160、秋季晴天中午。旧960×540仅作风格参考，不拉伸。
- 共用1280×720基础像素格，游戏2倍、母版3倍；独立透明道具按项目2倍密度规格交付。先用路米和16×32 NPC同屏校准门、台阶、桌椅，不按文件外框估人物身高。
- 母版至少分地面、建筑、树冠/屋顶前景、光/水/天气、独立互动道具；NPC、问号、文字、调查物不烘焙。
- 中心放事务所、图书馆、档案馆；阿飞摊和普通居民楼不默认挂任务。喷泉、树荫、报纸、公告板应能作为日常活动落点。
- 预留地先画庭院、花圃、空铺或菜园，可后续替换。不要画成21个醒目的施工警告或封锁任务门。
- 坐标是布局提议，房屋朝向、屋顶高度与装饰可美术调整；门、路、玩家站位和前景随图同步复核。不能只换底图不改碰撞。

## 九区分工

中心、老院巷/东、面包街/东、北区、南岸为七个城镇区：各3处主地点、2处日常建筑/摊位、3块预留地；河堤与北坡林是低建筑密度探索区，各最多一处轻量服务落点。完整建筑清单和12条双向路口在点位数据中。

住宅有晾衣、门铃、信箱、共用座位；商业街有陈列、遮雨棚和备货小空间；南岸保留栈桥、灯塔与潮声；河堤和林区保留自然留白，不靠复制商店填满。

## NPC与互动交付

先复用12位已交付常驻角色，首个生活样板优先老周、阿康、阿桃、小铃。需要喂鸽、遛狗、开店、修理等动作时先检验现有待机/行走/说话是否能组合；明确缺动作后再补帧，不整套重画。

物件需标出脚底/摆放锚点、交互站位、碰撞、可动范围与是否前景。代码绘制菜单、报纸文字、水位数字、门牌和提示；角色动作、天气与物件需能独立控制。

每栋建筑明确“可进入 / 门外服务 / 私人敲门 / 仅外观预留”；不是每栋都交室内，不是每栋都交任务图标。店门、桥口、出口与NPC工作站不能互相挡住。

## 复验

1. 中心灰盒配路米和一位NPC：确认可见身高、门尺度、步道宽度、前后遮挡。
2. 接老院巷和面包街：确认跨区不回弹、路线不穿屋、NPC对话后恢复活动。
3. 再出其余六区；每区分别交可走区、遮挡层与门/出口标注，不能九张全出完才看比例。
4. 正式图逐区替换并重建碰撞；截图要有玩家站在门边、桥边、家具边的对照。布局图通过不代表这些实机项通过。

既有小林空帧、天气道具奇数边等问题继续按 `acceptance/required-fixes-2026-10-18.md` 处理。汴京等暂停路线不纳入九区任务。
