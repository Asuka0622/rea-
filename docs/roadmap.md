# 后续路线：从网页预告版到正式版

> 2026-10-19，小克写。**这是正式版的后续路线，现在只是文档，不改代码**；网页版眼下只做第 1 节的收尾。这份文档是「接下来做什么」的总入口，取代 `docs/handoff.md` 第 2 节原来的迁移计划。
> 剧情看 `docs/story-prologue.md`、`docs/story.md`；第一部总设计看 `docs/concept.md`；美术需求看 `docs/art/asset-requirements.md`。

## 0. 一句话

网页版只做到**预告版（整个序章）**为止，用来验证剧情、玩法和难度。**正式版迁移到专业游戏引擎重做**，并且有三项网页版做不到的升级：

1. **NPC 接入本地运行的极小轻量文本模型**：镇上的人能按当时的情境自己说话，不再只念写好的台词；全程离线，不上传任何数据。
2. **动画全部升级成 CG 动画效果**：剧情演出从「定格图 + 对白框」变成引擎里实时渲染的过场动画，有镜头、灯光、表情和口型。
3. **人物、地图、建筑由引擎渲染**：不再是贴在网页上的整张 PNG，而是引擎里的模型和场景，有真实的光影、昼夜、天气和季节。

## 2. 正式版用什么引擎：Godot 4（2026-10-19 复核）

原定 Godot 4（2026-10-16）。新要求（CG 级过场、引擎渲染人物和建筑、本地文本模型）出来后重新比了一次，**结论仍是 Godot 4**。

| | Godot 4 | Unity（国内发行用团结引擎） | Unreal 5 |
|---|---|---|---|
| **AI 能不能直接改项目**（本项目主要由 AI 开发） | 场景、资源、脚本全是纯文本，命令行能跑测试和导出 | 很多事要在编辑器里点；场景和 prefab 是很长的带引用编号的文本，编辑器外改容易坏 | 资源是二进制，基本不行 |
| 实时过场 / CG 效果 | AnimationPlayer + 自己写演出代码 | Timeline + Cinemachine，最顺手 | 最强 |
| 三渲二 / 2.5D 人物 | 能做；模型、绑定、动画在 Blender 里做，glTF 直接导入 | 管线成熟，外包多 | 偏写实 |
| 本地小模型 | 有基于 llama.cpp 的插件 | 方案更成熟 | 要写 C++ |
| 平台 | 电脑、手机、网页；主机要第三方移植 | 团结引擎官方支持微信小游戏、鸿蒙；主机方便 | 包体大，手机吃力 |
| 费用 | 免费开源 | 收入过线要付费 | 收入过线分成 |

**选 Godot 4 的理由**：
1. **开发主要靠 AI**：纯文本的项目文件能让 AI 像改网页版一样读、改、比对、跑测试，这是决定性的一条。Unreal 因此第一个排除。
2. **CG 感主要来自美术本身**：模型、绑定、动画在 Blender 里做好（AI 也能写脚本驱动 Blender），引擎负责播放、光照和镜头，Godot 4 够用；过场工具比 Unity 简陋，用演出代码补（网页版的 `game-director.js` 就是这个思路）。
3. **本地小模型、昼夜天气、三渲二**都能做；免费开源，没有收费条款的风险。

**什么情况下改选 Unity（团结引擎）**：请人类引擎团队或外包工作室来做；或者微信小游戏、主机成了必须上的平台。只要有一条成立就换。

**怎么确认**：做一个两到三周的**垂直切片**，内容固定为「守夜 23:58」这一场：
- 北区一小块场景（钟楼 + 长椅 + 路灯，夜晚光照）；
- 路米和小克两个角色模型，能走、能说话、有表情；
- 一段 30 秒的实时过场（镜头推近钟楼、窗户亮起、指针抖动）；
- 一位 NPC 接上本地模型，能就「昨晚钟楼的灯」聊三句。

切片要验证两件事：过场能不能做出想要的 CG 感；本地小模型在中配电脑上的速度（见第 3 节）。跑通就开工；CG 感做不出来，再用 Unity 做同一个切片比较。

## 3. NPC 接入本地极小轻量文本模型

### 定位
- **写好的台词是主干，模型是枝叶**。剧情推进、教学知识点、委托线索、对质台词，一律用写好的文本（现有 `samples/cases/*`、任务数据、`npc-dialogue-data.js` 的 256 句情境对白）。模型只负责：闲聊、对玩家行为的即时反应、把同一句话换个说法、回答「镇上的事」。
- 理由：模型会说错。知识点说错就是教错；剧情线索说漏就是剧透。**这正是第一部的主题**（小克会一本正经地说错），所以游戏自己更要守住这条线。

### 模型
- **规模**：0.5B–1.5B 参数，4 位量化后约 0.3–1 GB，CPU 就能跑。中文要好、许可要允许商用，开工时从当时最新的开源小模型里挑（例如通义千问 Qwen 的小尺寸指令版）。
- **运行**：随游戏一起发布，离线运行（llama.cpp 一类的推理库，GGUF 格式）。**不联网、不上传对话**——游戏讲的就是「数据要经过同意」，NPC 不能自己变成悄悄统计。
- **性能目标**：中配笔记本上首字 0.3 秒内，一句话 1.5 秒内说完；内存 1.5 GB 以内。达不到就退回写好的台词，玩家不会卡住。

### 每次说话喂给模型什么
1. **角色卡**：身份、说话习惯、称呼（王奶奶叫路米「孩子」）、知道什么、不知道什么。数据从现有的人物设定和 `docs/world/npc-life-design-2026-10-18.md` 整理。
2. **当下情境**（从游戏状态里取，不让模型猜）：时间、天气、地点、玩家刚做了什么、哪些委托已经结案。
3. **可以说的事实清单**：按剧情进度开放。没结案的委托真相不在清单里，模型就说不出来。
4. **输出格式**：固定成 `{台词, 表情, 动作}`，限制字数。

### 守门
- 输出先过检查：字数、有没有清单外的剧情关键词、有没有不该出现的内容；不过关就换成写好的那句。
- 每位 NPC 配一套测试问题（一般闲聊、问剧情、故意套话、乱输入），模型或角色卡改了就重跑。
- **小克**：剧情里它说错的那几次是写好的戏，不交给模型。自由聊天可以用模型，但要求它对没把握的事说「我不确定」——和它在剧情里的成长线一致。

## 4. 动画升级成 CG 动画效果

现在的剧情演出是「定格图片 + 对白框 + 屏幕特效」（`public/story-fx.js`、`public/game-director.js`、`public/prologue-scenes.js`）。正式版改成**引擎里实时渲染的过场动画**：

- **镜头**：推拉摇移、景深、跟拍，不再是固定画面。
- **角色**：骨骼动画代替逐帧小人；面部表情和中文口型对得上台词。
- **灯光**：守夜的夜色、钟楼窗户一扇扇亮起、1843 伦敦的煤气灯和雾，都是真实光照，不是叠一层颜色。
- **可跳过、可回看**：看过的过场在任务日志里能重看。

**制作顺序**：现有的演出脚本（`prologue-scenes.js` 写的守夜、打开钟楼，外壳里的伦敦段）就是分镜的文字底稿 → 分镜图 → 动态分镜（粗模、定时长）→ 引擎过场成片。

**序章要做成 CG 的场次**（按优先级）：
1. 守夜 23:58（六个软件同时往钟楼送数据，指针抖动又停回 11:58）
2. 打开钟楼（门后是大电脑、星博士承认、镇上吵起来、小克问「我是什么」）
3. 时光机启动 → 1843 伦敦雾夜
4. 中点红线（镜头拉远，整面墙织满红线）
5. 开场：事务所开张、小克第一次登场

日常动作（走路、待机、说话、委托人的小动作）也一起换成骨骼动画，帧率和过渡都由引擎处理。

## 5. 人物、地图、建筑由引擎渲染

- **画面方向**：三渲二（卡通渲染的 3D）或 2.5D。人物保持现有设计：路米薄荷青短发、发夹、耳机、米色斗篷（男版同样识别特征）；小克是橙色像素蟹，在引擎里可以保留像素质感，做成屏幕或全息里的形象。最终风格在垂直切片里定。
- **地图**：九区的排法、路网、建筑落点、水系、出口，**直接用 `docs/world/town-v2-plan.json`** 搭场景。这份数据和引擎无关，就是为迁移准备的。
- **光影和环境**：昼夜、天气、季节由引擎实时计算。网页版的两个钟、`daypart` 调光、雨天叠层的规则都是需求说明，带过去用新方法实现。
- **室内和委托现场**：每个现场的物件、线索、互动点在 `samples/cases/*/workbench-case.json` 的 `puzzle.scene` 里，带过去照着搭。

## 6. 什么带过去，什么重做

| 带过去（和引擎无关的数据与设计） | 重做 |
|---|---|
| 剧情、台词、委托和谜题数据（`samples/cases/*`、`public/game-quests.js` 里的任务数据、`public/prologue-quests.js`） | 界面：对话框、任务日志、委托板、手账、技能树 |
| 九区规划数据 `town-v2-plan.json`、人物设定、NPC 生活设计和 256 句情境对白 | 地图、移动、碰撞、遮挡 |
| 教学案例和预先算好的报告（正式版不在玩家电脑上跑 REA） | 所有小游戏和动手实验的交互 |
| 难度、节奏、结业报告的规则（网页版试出来的） | 存档 |
| 美术设定稿、角色识别特征、色板 | 像素小人和整张地图（由模型和场景替代）、定格演出（由 CG 过场替代） |

**网页版当前美术怎么办**：预告版用到的像素素材照常做完、照常验收。正式版的模型和场景另出规格，引擎定下之后再写，现在不用准备。

## 8. 不变的原则

- 第一部只讲人工智能；主线讲基础，深的放传说任务（`docs/quest-tiers.md`）。
- 同一个知识点，不同阶段换不同玩法（`docs/knowledge-depth.md`）。
- 真相没有坏人；穿越的动机是「弄懂小克，再决定它的去留」。
- 玩家扮演路米，台词不分性别。
- 游戏里不写真实公司和产品的名字（小克的形象是用户指定的例外）。
