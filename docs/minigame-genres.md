# 把别的游戏类型借进来（格斗、经营、塔防、节奏…）

更新：2026-10-18。回应「可以把一些关卡做成格斗、模拟经营、解密等小游戏形式融合进来」。

## 0. 一条筛选规则

不是什么类型都能用。判断标准只有一条：

> **这个类型的核心动作，能不能和那个知识点的真实动作对上？**
> 对得上 → 玩得越深，学得越真（推荐）；对不上 → 只是糖衣，玩完学不到（不做）。

下面每一条都写清了映射。能通过这条规则的，我标 ✅；勉强能用的标 ⚠️（要做额外处理）。

## 1. 格斗 / 对战

- **✅ 朵朵 · 存档**：「客户端 vs 服务器」的攻防回合。
  你出招「改金币」→ 被「校验和」格挡；出招「连校验和一起改」→ 命中；出招「猜盐值」→ 被识破反打。
  **映射：出招 → 命中/被格挡 == 改动 → 被接受/被拒绝。**
  这一条非常干净：格斗的「哪一招有效」正好是存档分析的核心问题——客户端说了不算，服务器说了算。
  参考：《Divekick》（一招定胜负的极简格斗）、《Slay the Spire》的回合出牌。
- **⚠️ 小雨 · 彩蛋 vs 后门**：把「祝福」和「解锁专业版」做成两个对手，你要判哪个只是表演、哪个真能改变状态。
  需要先调研清楚才能做，否则容易把概念教歪。

## 2. 塔防

- **✅ 王奶奶 · 权限**：App 是一座城，**每个权限是一扇门**。敌人（广告 SDK、数据收集器）一波波来，
  你只开「闪光灯」这一扇必需的门，其余封死；门开得越多越难守。
  **映射：门越多越难守 == 权限越多攻击面越大。** 这是最小权限最直观的表达，比清单好十倍。
  参考：《Kingdom Rush》的简化版（3 波敌人、4 扇门）。
- **✅ 阿哲 · 密钥**：把「发布包」当战场，扫描塔照出密钥，你要在被拿走之前把密钥搬回服务器（搬走 = 修好）。
  参考：同上，加一个「扫描冷却」制造节奏。

## 3. 模拟经营

- **✅ 王奶奶 · 权限的代价**：经营一家手电筒公司。每给一项权限，广告收入↑、用户流失↑、被通报风险↑。
  目标：撑过若干天，且「灯一直能亮」。
  **映射：资源取舍 == 权限取舍。** 这一条把「为什么不能多要权限」变成可体验的代价，而不只是结论。
  参考：《Game Dev Story》的轻量经营、《Papers, Please》的家庭开销线。
- **⚠️ 小林 · 数据流向**：经营「数据水管」，把数据接到不同出口（同步/统计/广告），每接一条有收益和被查风险。
  概念对得上，但容易做得太重，建议做成经营的一个小切片（3 天）。

## 4. 节奏

- **✅ 小林 · 定时上报**：屏幕按 30 秒的节拍冒出「上传」，你要在拍点上切断（撤权限/断网），漏一拍就泄露一次。
  **映射：周期 == 节拍。** 「不是点了才上传，是它自己定时传」这个知识点，用节奏游戏讲最直白。
  参考：《Rhythm Heaven》《Crypt of the NecroDancer》的节拍判定。

## 5. 密室解密 / 机关盒

- **✅ 通用「打开入口」**：一个锁住的 App，玩家用收集到的线索（版本号、地址片段、快捷键）组合出打开方式。
  **映射：组合线索 == 排查入口。** 适合做「隐藏入口与后门」那一关（小雨）的另一种形式。
  参考：《The Room》的机关盒。
- **⚠️ 周姐 · 版本对比**：把「1.0 → 1.1 的变化」做成两个机关盒对比，找出多出来的零件。
  可行但不如时间线排序直接（时间线更贴补丁对比的真实动作）。

## 6. 卡牌

- **✅ 对质环节改造**：每张证据牌标注「能反驳哪类说法」，玩家在委托人的四句话里出对应的牌。
  **映射：出对牌 == 用对证据。** 这比现在的「翻证据列表选一个」更有决策感，也更好教「证据要对应主张」。
  参考：《Slay the Spire》的简化构筑 + 《逆转裁判》的举证。

## 7. 推箱子 / 管道

- **✅ 数据流向**：把数据包推过管道到正确出口，别推进广告管道；有些格子是「转发到第三方」的陷阱格。
  **映射：路径 == 数据流向。** 成本低，可以做成任意一关的过渡小关。

## 8. 不要做的（映射不成立）

- 赛车、射击（除了塔防的变体）、换装、跑酷：**核心动作和知识点对不上**，做了只会稀释教学时间。
- **判定**：如果一个类型里「玩得好」≠「想得对」，就不做。比如格斗里如果靠手速赢，就废了——
  所以上面的格斗是**回合制选招**，不是拼反应。

## 9. 三条硬约束（保证教学不失真）

1. **映射可逆**：玩家在游戏里做的决策，必须就是真实场景里的决策（开哪扇门 = 给不给权限）。
2. **失败要说知识**：输了显示「因为你开了 READ_CONTACTS，这一波从这里进来了」——不是「你操作不好」。
3. **时长 3–5 分钟**：小游戏是关卡里的一段，不抢主线时间，也不做成一个要练手的游戏。

## 10. 成本与顺序

| 玩法 | 成本 | 建议 |
|---|---|---|
| 塔防（权限） | 中 | **先做**：映射最干净，王奶奶关正好需要 |
| 节奏（定时上报） | 低 | 第二做：小林关的知识点正好是周期 |
| 经营（权限代价） | 中高 | 第三做：作为王奶奶关的另一种形式或复勘 |
| 卡牌（对质） | 中 | 改造现有对质，收益大 |
| 格斗（存档） | 中 | 朵朵关的改造，映射干净但要好好设计回合 |
| 推箱子 / 密室 | 低 | 随时可加，做过渡小关 |

## 11. 一句话

**借类型可以，但只借「核心动作等于知识动作」的类型。**
塔防的「门越少越好守」就是最小权限，格斗的「哪一招有效」就是客户端不可信，节奏的「拍点」就是定时器——
这些不是包装，是同一件事的另一种说法。

三个小游戏在 `public/case-minigames.js`，注册成沙盒的实验类型，谁都可以先单独试：

| 试玩链接 | 玩法 | 正式接在哪一关 |
|---|---|---|
| `?debug&mini=flashlight-apk` | 权限塔防：五波收集者分三类，措施各管一类，只留开灯要用的那个 | 王奶奶（`lab.kind = "tower"`） |
| `?debug&mini=weather-keys` | 数据流向：转管道把密钥接到「服务器」，别接到「发布包」 | 阿哲（`lab.kind = "pipes"`） |
| `?debug&mini=privacy-ledger&kind=rhythm` | 定时上报：红色上传拍点上按空格切断，绿色同步别切 | 待定（小林那关现在跑的是抓包实验，一个字段就能换） |

手感说明：

- **塔防**：收集者分三类（通讯录 / 定位 / 后台上传），措施各管各的——最小权限管「读」、沙盒管「发」、限速只拖慢杀不掉，克错的只打四折。所以铺满不再等于赢：得看清下一波来的是什么再决定放哪个、放哪儿。漏了会点名它是什么、该用什么挡。五波，约一分钟，波与波之间停手（钱继续涨）等玩家点「放下一波」。
- **管道**：点格子转 90°，接通服务器就完成；一旦接通发布包立刻提示走错了。出口有「服务器」绿牌、「发布包」红牌，「密钥」标在起点。
- **节奏**：一条 10 秒的轨道，拍点会亮；空格或点拍点判定，漏一拍记一次犯错。

三个都遵守「失败要说知识」：不是「你输了」，是「门开着，数据出去了」「密钥流进了发布包」。

## 13. 按两款参考重做（2026-10-18）

**塔防 ← 保卫萝卜 / 明日方舟**

| 借来的 | 用在哪 |
|---|---|
| 固定路径 + 沿路部署位 | 一条通道，右边来、左边是「隐私」，五个部署位（20/36/52/68/84）——**放哪几个也是决定**，全覆盖要三个且位置要错开 |
| 部署费用 + 自动回复 | 预算 20，每秒回 1.0；三种措施价格不同（最小权限 8 / 限速节流 5 / 沙盒隔离 10）。**开局只够放两个**，第三个得攒 |
| 单位可升级 | 点已部署的措施升级，伤害 ×1.6，价钱一样 |
| 波次递增 | 五波，2→3→3→5→6 个，血量 6→10、速度 10→12 递增；第四波起带「厚皮」精英（血 ×1.8、慢 0.7 倍） |
| 受保护目标 | 左边那扇「隐私」，漏一个掉一格，掉光就输 |
| 单位分工（新增） | 收集者分三类，措施各管各的：`strong` 命中打全额、不命中打四折；没写 `strong` 的（限速）一视同仁地弱，只负责 `slow` |

**教学映射没变**：部署费用 = 每项控制的代价；只有真该用的措施能挡住对路的那类收集者；漏了会说「泄出去了「后台上传」：它想定时把数据发走，你没点过同步。它的路上要放「沙盒隔离」」。

**为什么重做（2026-10-18）**：上一版三个措施只有伤害高低之分、收集者全都一样，开局预算 26 就能铺满三个位——**铺满即赢，没有决策**。现在：

- 措施有分工（最小权限管读、沙盒管发、限速只拖慢），克错打四折；
- 伤害改为单体（一次只打最靠前的那个），此前是范围内全体同时掉血，所以人多人少一样轻松；
- 预算砍到 20、波间停手等玩家点，让「攒钱换下一个措施」成为节奏；
- 顶部常驻「下一波 通讯录×2」预告，否则玩家无从判断该放什么。

**实测三种打法**（`.sandbox/towerbalance.mjs`）：无脑铺沙盒 → 隐私 0 输；只放最小权限 → 隐私 0 输；看类型出对应措施 → 隐私 2 赢。铺满不再等于赢，但正确打法也不会被卡死。

**节奏 ← 音游（Cytus / Muse Dash / 太鼓）**

| 借来的 | 用在哪 |
|---|---|
| 下落/横移谱面 + 判定线 | 拍点从右往左滑到判定线，红线 15% 位置 |
| 判定分级 | 距判定线 90ms 内「完美切断」，260ms 内「还行」，超过就漏 |
| 连击与准度 | 顶部实时显示连击、最高连击、准度、漏掉数 |
| 谱面按 BPM 生成 | `bpm` + `beat` 定义拍点，不用手填毫秒 |
| Miss 有后果 | 漏一拍就说「漏了，东西已经发走了」，并记一次犯错 |

绿色「同步」拍了也不能切——那正是「你自己要的同步」和「它自己偷偷传」的分界。

**经营 ← Game Dev Story / Papers, Please**

| 借来的 | 用在哪 |
|---|---|
| 日结账本 | 「过一天」结一次：广告进账、房租 ¥4、掉粉、风险上涨，逐日记账 |
| 每项事业一个开关 | 六项权限，开局全开（董事会接了广告 SDK），玩家负责关 |
| 收入与代价绑在同一开关上 | INTERNET +9/天但风险 +5；通讯录 +6/天还掉粉——想要钱就得担风险 |
| 撑过 N 天 | 7 天；用户跑光或现金烧穿 -¥20 都算倒闭 |
| 舆情事件 | 风险 40 商店问询（-15 用户）、80 通报批评（-30）、120 下架——**事件会点名风险最大的那项权限** |

实测弧线：全开 → 第 6 天被下架，结算点名叫 READ_CONTACTS；只留「闪光灯+联网」→ 零失误撑过 7 天，¥35。
结算语把取舍说破：「只留本职最安全，但也最穷——这就是最小权限的代价与安心。」

**卡牌 ← 逆转裁判（举证）**

| 借来的 | 用在哪 |
|---|---|
| 一句一句威慑 | 开发者的四句狡辩逐条亮出：「你不点同步它就不会传」…… |
| 出示正确的证物 | 六张证据牌常驻手牌，出对那张 → 「【等一下！】+ 为什么」，出错牌 → 说明这张牌**实际能证明什么** |
| 无关证物 | 「更新日志」「另一个案子的权限清单」是干扰项——错牌的教训就是「证据要对应主张」 |
| 逐句驳回后的爽感 | 4/4 驳回结算：「证据和主张一一对应，这就是证据链」 |

实测：先错出「更新日志」（记打错 1，提示它只写了修复闪退），再按序驳完四句，onDone 触发。

五个小游戏共同的三条硬约束仍然成立：开关/出牌 == 真实决策；失败点名具体权限/具体证据；单局 1–3 分钟。

## 15. 演出素材与视觉方向（2026-10-18）

五个小游戏目前全是代码占位（色块、文字牌）。把它们换成像素演出的逐件需求见 **[art/requests-minigames.md](art/requests-minigames.md)**（配套 `requests-minigames.csv`）。两条已经定下的视觉方向：

- **经营 → 日式 Q 版 3D 经营游戏**的观感：等距 45° 俯视、大头 Q 版小人、糖果色、店铺随经营变化、金币与表情粒子。用像素实现同样的观感，不做真 3D。店铺变化的落点：广告位贴画随权限组合切换——正经灯泡广告 / 读了通讯录后的「找朋友」/ 开了定位后的「附近」。
- **卡牌 → 逆转裁判式举证的构图**，场景是比特镇自己的会议室（重剧情，不上法庭）。这批是小游戏里美术要求最高的：对质场景、通用卡框（标题条留空由代码写）、六张「画物件不画字」的卡面插图，外加新角色「开发者」的立绘（方向稿先行）。

素材到位后的玩法增补（素材不阻塞、先记录）：经营可以加「顾客在店里走动、按权限组合换心情」的演出层，卡牌可以加出牌打空的晃头反馈——都是演出，不动判定。

## 经营改版：奶奶牌手电筒（2026-10-18，小克）

原版让玩家当一家手电筒公司、开局权限全开往下关：只有一个答案（留闪光灯+联网），而且玩家在剧情里是查小光的人，不该转头当它。改成王奶奶一案的**复刻练习**——案例结尾本来就写着「想一想，一个只要闪光灯权限的手电筒应该怎么设计」：

- 王奶奶请玩家做一个干净的手电筒，从 1.0 发到 1.8。每版一张提案，拍板后发布，跑一周结账（上架和服务器每版 ¥30）。
- 提案人都是剧情里的人：王奶奶、她的老姐妹们（SOS 闪烁、来电闪光）、**案子里查出来的 QuickAds 业务员**（「只需联网」，其实会合并四项权限，可以先用 REA 扫）、收小光数据的那家数据公司（卖通讯录 ¥120）。
- 唯一的核心规则：清单里每项权限都要对得上一个用户看得见的功能。说不清的敏感权限让王奶奶看到的安装弹窗吓跑人，1.3/1.6/1.8 审核第一次警告、第二次下架。
- 同一个权限可以说得清也可以说不清：来电闪光让「读手机状态」说得清；找附近五金店用大概位置说得清，用精确定位说不清。
- 删一项权限，要它的功能一起停；删相机灯就不亮（不少机型控制闪光灯要相机权限，和案例的判定一致）。
- 有多条通关路线：横幅广告 / ¥1 买断 / 先接 QuickAds 挨警告再整改。不赚钱会破产，什么都接会下架。
