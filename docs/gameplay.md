# 玩法研究：怎么让「学计算机」本身就好玩

> 2026-10-15，小克整理，供讨论；10-16 起第一部只讲人工智能（`docs/concept.md`，系列规划见 `docs/series.md`）。第 1–4 节的方法对整个系列通用。

## 1. 现在的问题

现在的玩法基本是「走路 → 对话 → 答题」。小游戏包装得再好，本质还是分类题、填空题，玩久了像练习册。

教育游戏研究里有个说法：**「巧克力包西兰花」**——游戏是外壳，题目是硬塞进去的，两者分开，玩家很快就会觉得「这是在考试」。研究里更有效的做法叫**内在整合**（intrinsic integration，Habgood 与 Ainsworth 2011 年的研究）：**玩法的规则本身就是要学的知识**，玩得越好，懂得越深。

## 2. 参考：把「学」做得好玩的游戏

| 类型 | 代表作 | 好在哪 | 我们能借什么 |
|---|---|---|---|
| 指令编排 | 《程序员升职记》（Human Resource Machine）、Lightbot | 用很少的指令卡让小人搬箱子，不知不觉学会了汇编、循环、跳转 | 打孔卡、钟楼指令、比比的行动程序 |
| 从零造电脑 | 《图灵完备》（Turing Complete） | 从一个与非门开始，一路搭出加法器、内存、CPU，每一关都是上一关的零件 | 1940 年代：亲手搭逻辑门和加法器 |
| 开放式解谜 + 成绩对比 | 《Opus Magnum》等 Zachtronics 游戏 | 一道题有很多种解法，通关后显示「你用了多少步、多少零件」，和别人的分布对比，让人想再优化 | **算法的快慢不用讲，玩家自己会想把步数降下来** |
| 流水线与物流 | 《异形工厂》（shapez）、《Mini Metro》 | 设计传送带和线路，吞吐量、堵塞、并行一眼就看得见 | 活字排版的两块铁板（流水线）、数据包路由、驿站分拣 |
| 推理与证据 | 《逆转裁判》、《奥伯拉丁的回归》 | 收集证据、出示证据、推出真相 | 侦探支线的推理板和对质（第 8 节）；安全、逆向、AI 核实 |
| 搜索数据库 | 《Her Story》 | 玩家自己输入关键词，在一大堆录像片段里搜，拼出真相 | **数据库和搜索**：侦探支线的代码搜索（第 8 节）；档案馆里自己写查询找线索 |
| 规则核对 | 《请出示文件》（Papers, Please） | 按越来越复杂的规则检查证件，放行或拒绝 | 中世纪城门：口令、印章、签名验证（身份验证、数字签名） |
| 嵌在故事里的谜题 | 《雷顿教授》 | 每个谜题都是剧情里某个人遇到的难题，解完有评分和收集 | 每个知识点都是某位角色遇到的麻烦 |
| 温馨日常 | 《星露谷物语》 | 每天有事做，和镇民建立关系，四季变化，慢慢把家布置起来 | 比特镇的日常、师傅的好感度、收藏和装饰 |
| 终端与黑客 | 《Hacknet》 | 真的输入命令行，像在用一台真电脑 | 硬核难度：在比特镇用真实的命令和代码 |

## 3. 我们的玩法支柱

1. **动手解谜（核心）**：每个知识点配一种机关，**机关的规则就是知识本身**。尽量做成**有多种解法**的开放题，通关后给评分（完成、步数、零件数），玩家会自己想优化，「快慢」「复杂度」不用讲就懂了。
2. **探索与推理**：在时代地图里找人、找线索；用推理、出示证据、搜索档案的方式推进剧情。
3. **比特镇的日常**：师傅的好感度（越熟越肯教你深的东西）、每日委托、复习信、四季、收藏各时代的纪念品来布置事务所。
4. **成长与收集**：技能树、成就、知识卡图鉴、每道谜题的星级、路米的时代装。

## 4. 机关类型清单（同一个时代不重复用同一种）

| 机关 | 玩法 | 教什么 |
|---|---|---|
| **指令卡编程** | 把指令卡排成一列，按「运行」看机器一步步执行；可以有循环卡、条件卡、跳转卡 | 顺序、循环、条件、函数、调试 |
| **搭电路** | 拖线连接开关、灯和逻辑门，点亮目标灯 | 逻辑门、二进制加法、时钟 |
| **流水线** | 摆放工位和传送带，让东西源源不断地产出；有吞吐量统计 | 流水线、并行、瓶颈 |
| **线路网络** | 在地图上连线路，让信件或数据包从 A 送到 B，有的线路会断 | 路由、冗余、TCP 重传 |
| **节奏与信号** | 跟着节拍发信号（烽火、摩尔斯电码），或者听信号解码 | 编码、时钟信号、协议 |
| **密码与破译** | 转动密码盘、统计字母出现的次数、试钥匙 | 加密、频率分析、暴力破解为什么慢 |
| **规则核对** | 一个个检查来人，按规则放行或拒绝，规则越来越多 | 身份验证、权限、签名 |
| **搜索档案** | 自己输入关键词或拼出查询条件，在档案里找线索 | 搜索、索引、数据库查询 |
| **调参实验** | 拖动几个参数，看曲线或机器的反应，找到合适的值 | 反馈控制、AI 训练、偏差 |
| **推理与出示证据** | 收集证据，在对质时出示 | 安全分析、逆向、核实 AI 的回答 |
| **小剧场经营** | 短时间内处理一串客人或任务（像《胡闹厨房》的简化版） | 队列、并发、调度 |

## 5. 第一部（人工智能）每个时代测试段的玩法草案（每段 2 个，不重复）

> 2026-10-16 起第一部只讲 AI（`docs/concept.md`）。原来全学科六个时代的玩法草案留档在 `docs/archive/concept-all-subjects.md` 和本文件的 git 历史里，以后的部可以用。

| 时代 | 第一段 | 第二段 |
|---|---|---|
| 开篇：REA 委托 | 解谜委托（第 8 节）：现场、代码搜索、手账推理、沙盒实验、对质 | 每案一种不同的动手实验（行为监视器、改存档、亲手试彩蛋……） |
| 一 · 1843 伦敦 | **排运算卡**：帮爱达把分析机的运算卡和变量卡排对，算出伯努利数；用「重复」省掉一大摞卡（指令卡编程 + 循环）。她的原稿里真有一处错，玩家要找出来 | **音符也是符号**：把一段旋律编成数字，再让机器照规则变奏（编码 + 规则就是程序） |
| 二 · 1950 / 1956 | **模仿游戏的裁判**：隔着电传打字机和两个对象聊，判断哪个是机器；再看几个小技巧怎么骗过裁判（推理 + 测试的局限） | **研讨会的提案**：把一堆研究想法分成几个方向，写进提案（分类整理；硬核难度：用搜索在小迷宫里证明一条定理） |
| 三 · 1970 年代 | **写规则**：把医生的经验拼成「如果……那么……」规则卡，看程序一条接一条推出诊断（规则核对的变体 + 推理链） | **几分把握**：证据不全时给结论打分，再遇到规则外的病例，看系统怎么出错（调参实验 + 不确定性和边界） |
| 四 · 1997 纽约 | **博弈树**：在一盘残局上展开「你一步我一步」，给末端局面打分，剪掉不用算的分支，比一比算了多少步（搜索 + 剪枝；评分看算的步数） | **调评估**：拖动「子力、位置、王的安全」几个权重，看机器下法怎么变（调参实验 + 评估函数） |
| 五 · 2012 / 2016 | **训练看图**：标注图片、分训练集和测试集，训练一个小网络；故意让它「背题」，看测试分数掉下来（调参实验 + 过拟合） | **自我对弈**：在一个小棋盘上让 AI 和自己下几百盘，看策略一点点变强（强化学习） |
| 六 · 2017 至今 | **接下一个词**：看模型给每个候选词的概率，一个词一个词接出句子；点亮注意力连线（预测下一个词 + 注意力） | **核实回答**：AI 给了一个很像真的出处，在档案里搜索，证明它是编的（搜索档案 + 推理） |
| 终章 | **钟楼对质**：用六条证据和六个时代带回的东西，戳穿悄悄统计的说法（推理与出示证据） | **重新教比比**：挑选经过同意的数据，设评估，留下人工复核（调参实验 + 责任） |

每段解完都有评分：轻松看「完成」；标准加上「步数」；硬核再加上「零件数」和挑战条件。

## 6. 已定（2026-10-15）

1. **整体手感：A，温馨 RPG + 谜题关卡**（像《星露谷物语》加《雷顿教授》）。在世界里走、和人聊，谜题嵌在剧情里，每道谜题是某位角色遇到的麻烦。
2. **硬核难度试着加入真正写代码**：先在比特镇的「回来对照」环节试做（比如用几行 JavaScript 做一遍刚在时代里用机关做过的事），效果好再推广。
3. **评分和别人比：暂定**。先只显示自己的成绩（完成、步数、零件数）；以后再决定和「镇民平均」比，还是联网比。

## 6.5 「写代码」的形式（2026-10-15 定）

写代码**不局限于编程语言**，真正的编程语言只占极少部分。计算机里的「代码」本来就有很多种形式：

| 形式 | 用在哪里 | 教什么 |
|---|---|---|
| **指令卡积木**（原 `public/game-cards.js`，2026-10-19 随旧主线从网页版删掉，留给系列「编程」那一部） | 钟楼、织布机、拆数…… | 顺序、循环、条件、边界情况 |
| **中文口令和步骤** | 古代中国（《九章算术》的「术」就是一步步的口诀） | 算法就是写清楚的步骤 |
| **打孔卡** | 工业革命 | 程序可以存在卡片上 |
| **电路图** | 1940 年代 | 逻辑门是硬件里的代码 |
| **标签积木**（HTML） | 1960–90 年代 | 标记语言 |
| **查询条件**（像 SQL，用中文拼） | 档案馆、数据支线 | 数据库查询 |
| **表格公式** | 数据支线 | 电子表格也是编程 |
| **提示词** | 现代都市 | 用自然语言让 AI 干活 |
| **真正的编程语言**：Python、C、C++、JavaScript，玩家自己挑 | 硬核难度里写真代码的题目 | 用自己会的语言解决游戏里的问题 |

**写真代码的题目不限定语言**（原 `public/game-code-runner.js`，2026-10-19 随旧主线删掉；做法留给系列「编程」那一部，要看代码去 git 历史）：题目按「在线评测」的方式出——程序从输入读数据、打印答案，游戏用几组测试数据去比对输出，所以任何语言都能用同一道题。
- 现在支持：**Python**（Pyodide，第一次要下载约 10 MB 的运行环境，之后有缓存）、**C / C++**（JSCPP 解释器）、**JavaScript**（浏览器自带）。都在独立线程里运行，两秒跑不完就判为死循环并停掉。
- 默认打开 Python；每种语言有自己的起始模板，切换时已写的代码会保留；还有「指令卡」标签给想拼积木的人。
- Python 和 C 第一次需要联网下载；断网时提示改用 JavaScript 或指令卡。
- 以后要加别的语言（比如 Java、Lua），只要在运行器里加一种。

第一个例子：硬核难度在铁叔工作台的「拆数程序」：读一个整数 n，从高位到低位输出每一位。

## 8. 侦探委托的解谜结构（2026-10-16 定）

用户反馈：委托「太简陋」。原来的流程是路米一条条出题，玩家去报告里点答案，本质是问答。改成解谜关卡，参考：

| 参考 | 借来的东西 |
|---|---|
| 《金色偶像案》《奥伯拉丁的回归》 | 收集词语，填进推理句子；**一组全部对了才盖章**，错了只说「差一点」或「还不对」，不逐格判对错 |
| 《Her Story》 | 没有线索清单，**自己想关键词搜**；搜到的片段里又有新的名字可以接着搜 |
| 《逆转裁判》 | 对质：逐句「追问」或「出示证据」；不是每句都是假的 |
| 密室逃脱 | 现场的东西点开有线索，线索告诉你该去找什么 |

### 一份委托的流程
1. **现场**：委托人的房间。点里面的东西，得到线索（记进笔记），同时**小词典**多几个「中文 → 代码里可能的名字」，比如「剪贴板 → clipboard」「每隔一段时间 → setInterval」。也有没用的东西（窗台上的猫）。
2. **代码搜索**：搜 REA 拆出来的代码。**发布版没有开发者注释**，搜中文搜不到，必须用小词典里的英文名去搜，这本身就是要学的：代码里的名字就是线索。结果最多显示 6 条，太多会提示「加一个词缩小范围」。代码里带下划线的名字可以点，记进笔记；关键的一行可以「记成证据」。
3. **推理板**：用记下的名字补句子。比如「没有按钮的 ＿＿，被 ＿＿ 每 ＿＿ 毫秒调用一次，把读到的剪贴板文字存进 ＿＿」。干扰项来自代码里真实存在的其他名字。
4. **动手实验**：推理只是推理。把样本放进沙盒真跑一遍，亲眼验证推理板上的每一条（实验见 `public/case-labs.js`）。实验抓到的东西也会成为证据。
5. **对质**：委托人拿着软件的说法（比如隐私说明）一句句念，玩家追问或出示证据戳穿。有真话，也有要靠实验证据才能戳穿的话。
6. **结案**：评星看犯错和问路米的次数（0–2 次三星，3–6 次两星）。

**每份委托要有一个「反转」**，从样本代码里真实存在的东西挖。小林的委托里，剪贴板第一次运行时不会被发走，被定时器存下来以后，要等**下次启动**才跟着设备信息一起发出去，所以只跑一次是抓不到的。

### 呈现：在世界里查案，不是在网页里答题（10-16 晚）

用户反馈「还是不够有作为游戏的沉浸感」。原因是案子装在网页窗口里，操作是标签页和下拉框，人也不在场景里。改成：

- **走进委托人的房间**（`game-shell.js` 的案发现场房间）：主角在房间里走，委托人站在里面。没看过的东西头上有「?」，走近会发光，按 E 调查。线索记进手账时有音效，右下角的手账会跳一下。
- **侦探手账（N）**：一本像素风的书，右边是书签：线索、小词典、名字和证据、推理。推理页把名字卡**拖进**句子的空格（也可以点卡片再点空格），一条全对时「盖章」，章会砸下来。
- **用委托人的电脑查代码**：走到电脑前按 E，打开 REA 终端，像《Hacknet》一样输入 `find clipboard`。每条结果连带上下两行代码，黄色的名字点一下就飞进手账。推理拼好之前，`sandbox` 命令会拒绝：「还不知道要验证什么」。
- **沙盒在同一台电脑上**：输入 `sandbox`，抓包仪也是终端的样子。抓到的请求自动记为证据。
- **对质是一场演出**：全屏，路米和委托人的立绘一左一右，说法用大卡片打出来，◀ ▶ 翻看。出示对的证据会出现「异议！」大字、震屏和音效。最后盖「结案」章，给出星级。
- 脚步、翻页、敲键盘、盖章、抓包提示音、紧张的配乐都是合成音效（`game-sound.js`），可以在顶栏关掉。

网页模式（不进游戏时）仍然用 `case-puzzle.js` 的面板版，玩法相同。

### 数据格式
写在 `samples/cases/<id>/workbench-case.json` 的 `game.puzzle` 里：`room`（地面、出生点、门、委托人站的位置、和委托人说话时的台词）、`terminal`（哪件东西是电脑）、`scene`（房间物品的位置 `at`、站在哪里调查 `stand`、线索、小词典）、`terms`（可以收集的名字）、`board`（推理句子，`{答案}` 是空格）、`labTasks`（实验任务改成验证推理的说法）、`labEvidence`、`confront`（说法、追问、能戳穿它的证据）。`test/case-puzzle.test.mjs` 检查：从小词典的词出发一路搜下去，能找到推理板的每个答案；每个小词典的词都能搜到东西；每句假话都有证据能戳穿。

## 2026-10-17：试玩三关改成探索与推理

参考独立叙事解谜的“探索 → 观察 → 提出解释 → 用证据检验”循环。Lucas Pope 的[官方游戏介绍](https://dukope.com/)将《Return of the Obra Dinn》描述为基于探索和逻辑推理的神秘冒险；这里借鉴循环，不使用其素材、角色或关卡。

- 三关都有可自由调查的房间、可选物件、实际源码、三段推理、动手实验和真假混合的对质。线索不要求固定收集顺序；帮助由玩家主动请求。
- 小林：从软件行为和源码找到数据流向，在隔离实验中检验。
- 朵朵：发现看不懂的存档，区分编码和加密；先观察直接修改被拒绝，再按规则重建副本。
- 小雨：先找入口并触发效果，再区分显示彩蛋、调试能力与授权变更。
- 推理题的名字和支持证据必须能从各自样本找到；实验完成才记录实验结论；结案后有对应的复盘。
- 新关卡共用自动存档与点击寻路。场景仍使用可交互占位画面，正式美术以素材交付文档为准。


## 2026-10-17：六个委托要六种玩法（方向调整）

用户反馈：三关都是同一套「搜源码 → 拼推理板 → 沙盒」，玩到第三关就腻了。方向改成**六个委托手上的动作各不相同**：盖章、找、按、算、比、布（分别对应 Papers, Please、Hidden Folks、FEZ、Zachtronics、Her Story、Baba Is You 一类玩法），但共用同一套侦探外壳——走动调查、手账、对质、三档难度与存档。详细设计、每关的界面与难度、数据格式和实现顺序见 `docs/case-mechanics.md`。

本章第 8 节描述的「搜索 + 推理板 + 沙盒」保留为**默认玩法**：没有写 `mechanic` 的委托照旧用这一套，写到哪一关就换哪一关。

本轮完成的是试玩三个委托的关卡结构，不代表第一部六个 AI 时代、所有美术或 Godot 正式版已经完成。连续通关事件可到结尾领取见习侦探徽章；浏览器操作验证与逻辑回归分开记录。


## 2026-10-18：行动点与心证（张力层）、侦探工具（成长层）

用户反馈「所有游戏玩法还需要完善」。诊断：关卡本身不糙，缺的是**包住关卡的张力与成长**——
调查不限次、搜索不限次、对质错了就重来，解谜没有代价；技能树只有图鉴、没有成长。本轮先补这两层里最小的一圈。

### 行动点（行动预算）

- 每份委托按难度给预算：轻松 20 / 标准 15 / 硬核 11（`public/case-tension.js` 的 `BASE_BUDGET`）。
- 花 1 点：第一次调查某个物件、每次终端搜索。花 2 点：问路米一次。
- **永不阻止玩家**：超出预算的每一笔记一次「超支」，直接计入星级，避免玩家卡死在无解状态。
- 目标条常驻显示 `行动点 剩余/预算 · 心证 ♥♥♡`；超支时弹一次提示。

### 心证（对质的生命）

- 对质有 3 条心证；出示错一件证据 −1，同时照旧记一次失误。
- 扣光 → 「当庭失败」画面：**重新对质** / **先去补线索**。两条都恢复 1 条心证、记 1 次失败（星级 −1，最低 1 星）。
- 失败不是终点：手账和证据都保留，玩家补齐线索再回来。

### 侦探工具（成长）

按已结案委托数解锁，对之后每一份委托生效，结案卡上会提示：

| 工具 | 解锁 | 效果 |
|---|---|---|
| 放大镜 | 结案 1 份 | 每份委托 +3 行动点 |
| 速记本 | 结案 2 份 | 问路米只花 1 行动点 |
| 终端别名 | 结案 3 份 | 终端可以直接用中文查（借手账小词典映射成代码里的名字） |

### 落点与验证

- 规则：`public/case-tension.js`（纯函数，无 DOM）；存档：`public/case-progress.js` 增加 `spent / hearts / fails`；
  呈现：`public/case-session.js`；难度与已解锁工具由 `public/game-shell.js` 传入。
- `test/case-tension.test.mjs` 11 项（预算、超支、心证、星级、解锁表、别名、存档往返、脏存档钳制），全量回归通过。
- 还没做：技能点商店（现在按结案数自动解锁）、三份「报告式」委托（阿哲 / 周姐 / 王奶奶）的同等张力、
  以及 `docs/case-mechanics.md` 里六个委托六种玩法的落地。
