# NPC 行为逻辑

> 2026-10-18。现状：12 位小镇常驻 [npcs.md](art/npcs.md) + 6 位序章人物，全部是**站在固定坐标上的路标**——
> 走近、说 `first`、之后再走近只说 `after`（`public/npc-chatter.js`）。位置永不变、时间永不变、
> 彼此不认识、也不记得你做过什么。这份文档设计的是把他们变成**住户**。

## 0. 三条设计原则

1. **行为必须是教材，不是装饰。** 本项目教的是隐私与权限。小镇上每个人身上都挂着一件事
   （见第 6 节）：老宋看鞋底就能说出你常走哪条路——那是**真在记录你的轨迹**；小石头的头版
   永远是同一张——那是**缓存不更新**；阿康把告警按掉四百次——那是**告警疲劳**。这些知识点
   现在写在台词里，行为逻辑要把它们**演出来**：让玩家先看见，再听懂。
2. **不靠数值。** 不显示好感度、不出信任条。关系的进展体现在**称呼**（"你"→"侦探"→直呼其名）
   和**他们愿不愿意把话讲完**（欲言又止 → 说完 → 主动来问你）。
3. **先看懂，再系统化。** 分四层叠加（第 2-5 节），每层单独成立，可以只做第一层就上线。
4. **没有事的 NPC 不上街。** 这条是硬规则，用来卡住"装饰性走动"：
   - 街上出现的每个人身上都必须有**一件正在进行的事**。没有事的就在屋里、学校里、档案馆里——
     他们靠别人的闲话存在，不占画面（第 6.4 节列了谁该消失）。
   - **位移必须指向目的**：从一件事走到另一件事（送报、收摊、开格子、追人、对表、回家）。
     会动的人，每一个都要能回答"他现在去干什么"。答不上来的走动一律删掉。
   - **街上同时可见 2-5 人**。小镇像有人住，靠的是"该有人时有人、该没人时真的空"，
     不是到处站着人。夜里和清晨街上就该是空的。

## 1. 时间怎么走：故事钟，不是挂钟

小镇现在**没有时间系统**（只有钟楼停在 11:58 这一个剧情状态）。引进四段：

| 阶段 | id | 天色 | 这个时段镇上正在发生什么 | 由什么推进 |
|---|---|---|---|---|
| 清晨 | `morning` | 冷白偏蓝 | 早市开门：摊贩推车到位，街上只有摊主 | 完成 1 份委托、或从案件回到镇上，推进一段 |
| 白天 | `noon` | 明亮 | **购物潮**：手艺街有人排队、拎着袋子走 | 同上 |
| 傍晚 | `dusk` | 暖橙 + 窗里亮灯 | **放学潮** + **下班潮** + 各家亮灯 | 同上 |
| 夜里 | `night` | 深蓝 + 窗灯 + 路灯 | 人散尽，只剩老陈提着灯 | 同上，走到头回到 `morning` |

时段不是背景设定：每一段都自带一场**人潮**（第 5 节）。

**推进规则：完成一份委托 = 走一段。** 不做真实计时（等人是坏体验），也不做"走到某处触发"（不可控）。
存在存档的 `world.phase` 里，和 `discovered` / `accepted` 同级。

这个规则和钟楼那条线是同一个梗：**镇上没有准点了，时间由你做了什么决定。**

天色实现：地图上层一张色罩 + 窗灯（spots 上两个暖色小方块），全部代码画，不需要素材。

## 2. L1 生活节奏：四个时段，四个位置

每人一张作息表。切段时从当前位置**沿路点走过去**（速度 22px/s，走路动画 6 帧）；到了就停下做动作。

```js
{
  id: "cobbler", name: "老宋", region: "craft",
  routine: {
    morning: { at: [520, 300], act: "open" },          // 开摊：把工具摆出来
    noon:    { at: [520, 300], act: "cobble" },        // 钉鞋：一下一下
    dusk:    { at: [520, 300], act: "cobble" },
    night:   null,                                      // 收摊了，不在街上
  },
  // act 跟着做的循环动作：站/坐/擦/钉/扫/翻/喂/按/修
  acts: {
    open:   { every: 0, say: "（把鞋楦一只只摆到脚边）" },
    cobble: { every: 2.4, say: "（锤子落下去，鞋钉咬进木头）" },
  },
}
```

规则：

- **每一条位移都要有目的**（送报、收摊、开格子、追人、对表、回家），没有目的的不做。
  单纯的"换个地方站着"不算行为，是装饰。
- **没有事的 NPC 不在街上**：`night` 写 `null` 就是真的不画，清晨/傍晚该收摊的也收摊。
- **玩家不在的图里也要跑**，否则切图回来会看见人卡在半路。实现：位置是 `phase` 的纯函数，
  玩家切图/切段时直接就位；只有在**同一个图里**看到的才是走过去的过程。
- 位移更新走主循环里改 `style.transform`，**不要每帧重建 DOM**（现在 `npcEls()` 在 `render()` 里，
  切图重建是对的，逐帧不要碰）。
- 位置不进存档——每次按 `phase` 算出来，存档只存 `phase`。

## 3. L2 情境：他现在在做什么，决定他说什么

现在台词只有 `first` / `after` 两档。加两档：

| 状态 | 台词档 | 例 |
|---|---|---|
| 刚认识 | `first` | 老周："钟楼没停之前，镇上没人看表。" |
| 他正忙着 | `busy` | 大壮正搬箱子："等我这箱——24 个格子，一天 60 个人。"（**忙着也在教东西**） |
| 你刚问过 | `repeat` | 老周："你又来了。鸽子都认识你了。"（防复读，第三次起） |
| 很久没来 | `after` | 现在的 `after` |

`busy` 的判定：他正在做一件每 N 秒循环的动作（钉鞋/擦灯/按手机）时走近。

**两人对话**（成对 NPC 挨着时自动成立）：走近小铃，她和老魏各说一句：

```
小铃：「0.5 秒也是误差。」
老魏：「0.5 秒也是准的。」
小铃：「那 1 秒呢？」
```
——玩家不用点，走近就听见一段戏。

## 4. L3 记忆与传播：镇上会传话，也会记着你说过的话

**记忆三件事**（都存在 `world`，不显示）：

1. 你答应过、还没做的事 → 委托人到你家门口转圈（见第 5 节 pending 的踱步）。
2. 你在案件里怎么做的 → 存成 `world.choices`，例如 `flashlight-apk:contacts-off`。
3. **你走过的路** → 玩家每进一个区域记一次序列，老宋会读它（第 6 节）。

**传播**：完成一件事后，写进 `world.gossip` 队列，谁跟谁认识就传给谁（下表），下次聊天时
由对方提起来——**世界在你做了事之后会自己动一下**。

| 传播链 | 谁跟谁 |
|---|---|
| 老周 ↔ 小石头 | 广场上的人：报童 → 老周 → 阿飞（广场边摊） |
| 老魏 ↔ 小铃 | 师徒，钟楼下 |
| 阿桃 ↔ 小鹿 | 手艺街两个铺子，互相串 |
| 阿康 ↔ 大壮 | 住宅区，快递与告警 |
| 老陈 | 孤，南岸；只从老周的旧事里出场 |

## 5. L4 时间与群体事件：小镇按点一起动

### 5.1 每天按点发生的事（跟着 `phase` 走，进时段就演一次）

| 时段 | 事件 | 表现 | 它在教什么 |
|---|---|---|---|
| 清晨 | **早市开门** | 阿飞推车到广场边、老宋摆工具、阿桃支起摊——三个摊主先后到位（推/搬/摆三个动作），街上从空到有人 | 街道是"醒过来"的，不是一开始就有人的 |
| 白天 | **购物潮** | 手艺街进来 3-4 个购物者（第 6.5 节）：面包摊前排队 2-3 人，前一人走了后一人补位；买完手上多一个袋子，走向下一个摊位 | **消费记录**：你买过什么、几点买，店里都留着 |
| 白天 | **快递车到** | 一辆车（一个小色块）停在快递柜旁，大壮把包裹一件件塞进格子，柜子由空变满 | **队列与容量**：一天 60 人、24 个格子 |
| 傍晚 | **放学潮**（重头戏） | 4-6 个小个子从学校方向成群出来，两人一排边走边聊，到路口散开，各自走进家门消失；一位家长在路口等，接到孩子后两人并排走回家 | **规律作息 = 可预测**：每天这个点这条路上都是小孩，站一天就数得清谁家有几个孩子、几点到家 |
| 傍晚 | **下班潮** | 2 个提包的人从北区方向走进住宅区，各自进屋 | 同上 |
| 夜里 | **散场** | 摊主收摊（三个摊依次变空），窗灯亮起，街上只剩下南岸那个提灯的人 | 空，本身就是信息 |

### 5.2 特殊事件（不按点，按剧情）

| 事件 | 触发 | 表现 |
|---|---|---|
| 钟楼修好那晚 | 主线终点 | 全镇 NPC 位移到中心广场，站着不动，抬头。届时 `phase` 被事件接管，全场不散场 |
| 快递柜满了 | 大壮支线进行中 | 柜子前排 4 个人，大壮边喊边跑到柜子另一头敲格子 |
| 阿康的手机 | 走近他时随机响 | 他停下、看一眼、按掉（三个动作），第四次响时他说"……万一这次是真的呢" |
| 鸽子扑棱 | 走近老周 | 三个灰点从他脚边散开（复用落叶粒子，不需要素材） |

### 6.2 支线六位（新加，先摆摊，不进屋）

手艺街和住宅区现在**没有她们的门**（`game-regions.js` 里那几个 spot 都是 `soon`），
所以她们先**在街上摆摊**——摊位是代码画的一个小色块 + 她本人，走近就开口。
等店铺图补上（见第 8 节），再把人挪进门。

她们不"站在店里等玩家"，每个人身上有一件正在发生的事；事没发生时就不在街上。

| 人 | 位置 | 作息（**没写的时段 = 不在街上**） | 他会动一下的时刻 → **理由** | 知识点 |
|---|---|---|---|---|
| 阿桃 `baker` | 手艺街 (430,270) | 白天在摊前；傍晚**走到广场边** (600,380)；夜里不在 | 她拿着外卖单走去广场，**看今天自己排第几**——一成不变是第 6，看完回店里 | **排序公平**：算法不说为什么，但结果有规律 |
| 小鹿 `barista` | 手艺街 (560,300) | 白天/傍晚在柜台后 | 便签乱了以后她**追出柜台几步**(→520,320) 把写错的便签递给你——她在追人，不是在站 | **记录 vs 记忆**：记下来就安全了吗，记错了呢 |
| 老宋 `cobbler` | 手艺街 (520,300) | 清晨开摊→白天钉鞋→傍晚收摊 | 你走近，他**抬头看你脚上的鞋**，说出你常走哪条路（读玩家真实区域序列） | **轨迹数据**：你走的顺序，鞋底全记着 |
| 阿飞 `disk-vendor` | 广场边 (620,430) | 白天/傍晚蹲摊 | 他不闲逛，他**把一块硬盘塞给你**——你手上是上一位主人的东西 | **删除 ≠ 消失** |

| 老陈 | 他例外——夜里他在巡灯，所以他**恰恰是夜里街上唯一的人** |

### 6.5 流动人群：会购物、会放学的路人（没有名字，不说话）

小镇要有"人潮"，就不能只有 12 位常驻——还得有一批**临时生成、用完就走**的路人。
他们**不进 `CHATTER_NPCS`**（没有名字、没有 `first`，走近多半只说一句"借过"），
走近也不记 `talked`，因为他们不是角色，是人流本身。

```js
export const CROWD_EVENTS = [
  // 一批人：什么时候、从哪来、去哪、几个人、去干什么
  { id: "shoppers", phase: "noon", region: "craft", group: 3,
    path: [[900, 300], [430, 270], [520, 300], [300, 420], [60, 300]],
    kind: "shopper", stops: [430 * 0 + 1, 3], act: "buy" },
  { id: "school-out", phase: "dusk", region: "homes", group: 5,
    path: [[880, 120], [640, 300], [450, 430], [340, 440]],
    kind: "student", ends: "home" },
];
```

| 人群 | 时段 | 长相 | 他们在干什么 |
|---|---|---|---|
| 购物者 `shopper` | 白天 | 提着袋子的人，2-3 套配色轮换 | 进店→摊位前排队→停 2-5 秒（真在买）→手上一个袋子→走向下一个摊位→出街 |
| 放学学生 `student` | 傍晚 | 小个子，背书包，两人一排 | 成群出校→边走边聊→到路口散开→**走进家门消失** |
| 下班的人 `commuter` | 傍晚 | 提包，步子慢 | 从北区方向进住宅区→进屋 |
| 等孩子的家长 `parent` | 傍晚 | 站着不动 | 在路口等→接到人→并排一起走回家 |
| 排队的人 `queue` | 白天 | 站成一列，间距 14px | 前一个人走了，后面的人补上去（面包摊/快递柜共用这套） |

规则（同样受第 0.4 条管）：

- **人数随时段变化**：清晨 0-1 人、白天 3-5 人、傍晚 4-6 人（放学那一波最密）、夜里 0 人。
- **他们是"成组"的，不是散的**：购物者排队、学生成排，看得出是一件事，不是一堆人在晃。
- 造型只要 3-4 套（无名路人共用），不需要每人一套。

## 9. 已知的坑

- **切图就位**：位置必须是 `phase` 的纯函数，切图/切段直接算，别把半路的位移带过去。
- **别每帧重建**：`npcEls()` 现在在 `render()` 里；逐帧更新改成持有元素改 `transform`。
- **碰撞**：NPC 不参与碰撞（会卡住），但**穿过玩家不好看**——走近时让他停下来说话，就自然停了。
- **跨区的成本**：报童跨区位移在玩家离开后仍要算（纯函数按时间插值），别只在可见区更新。
- **别剧透**：`busy` 和 `repeat` 的台词也要过一遍"这句话有没有把没发生的剧情说出去"。
