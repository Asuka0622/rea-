# 剧情简单，技能树里加深

更新：2026-10-17。**第一部只讲人工智能**（`docs/series.md`），这份文档说的是「剧情一层、副本一层」的整体结构，以及副本怎么接进现有技能树。

## 1. 两层，各管一件事

| 层 | 给谁 | 难度 | 结果 |
|---|---|---|---|
| **剧情层**（主线 + 六个 REA 委托） | 完全没接触过 AI 的人 | 一定能过：线索齐、有提示、走错了也不会卡死 | 点亮技能、推进故事、拿到证据 |
| **副本层**（技能树里的进阶任务） | 已经看懂的人 | 同一条知识线，逐级加码：没有提示、有干扰、限时、只给一次机会 | 星级、掌握度、解锁下一级 |

一句话：**剧情负责「讲明白」，副本负责「真的会」**。剧情里不惩罚，副本里才有评价。

## 2. 第一部的知识线只有两条

`game-skills.js` 里每个分支标了 `part`：

| 分支 | part | 在本作里 |
|---|---|---|
| **安全**（数据流向、密钥、权限、后门、文件格式、版本对比…） | 1 | 序章 REA 篇的教学线，六个委托对应六个技能 |
| **AI**（机器学习、训练数据、偏见、神经网络、大语言模型、提示词…） | 1 | 主线六个时代的教学线，随章节开放 |
| 电脑 | 2 | 留给「计算史与计算机基础」那一部 |
| 网络 | 3 | 留给「网络与互联网」那一部 |
| 编程 | 4 | 留给「编程与软件」那一部 |

技能树只显示 `part === 1` 的分支，并在树顶写一行说明，免得看起来像少了东西。数据都留着，做后面的部时把 `part` 改掉就回来了。

## 3. 副本长什么样

- **位置**：技能树和副本**分成两页**（技能树顶部标签：安全 / AI / 副本 / 成就）。技能树的格子里只写「这一格有 3 个进阶副本」，点进去要切到「副本」页；副本页左边按分支列出有副本的技能，右边是这一格的三个副本和星星。技能点亮（剧情委托做完）才开第一级。
- **三级阶梯**：熟练 → 精通 → 专家，每级一个副本。上一级拿到 2 星才开下一级，专家要 3 星。
- **同一关、更少帮助**：副本复用这个技能的剧情房间和谜题，改的是「帮助」和「容错」：

| 加码方式 | 具体做法 | 现在实现了吗 |
|---|---|---|
| 拿掉提示 | 手账里的「问路米」消失，提示条只说该干什么不说怎么做 | 已有 |
| 干扰词 | 小词典混进两个样本代码里根本没有的词，搜了白搜 | 已有 |
| 限时 | 顶部出现倒计时（专家级） | 还没 |
| 容错 | 对质只允许错一次 | 还没 |

- **打分**：一次不犯错、不求助 = 3 星；犯一次或求助一次 = 2 星；更多 = 1 星（`starsFor`）。重复挑战只记最好成绩，不会因为重玩把记录拉低。
- **掌握度**：技能卡片上显示「已通关 x/3 关 · y/9 星」，全 3 星算「精通」。
- **不污染剧情存档**：副本的进度点单独存（`rea-case-checkpoint-v1:<case>:drill:<drill id>`），副本里存的东西不会顶掉剧情进度。

## 4. 数据与代码

| 文件 | 作用 |
|---|---|
| `public/game-drills.js` | 副本数据（每个技能的三个副本、加码开关、干扰词）和解锁/打分/掌握度的纯函数 |
| `public/game-skilltree.js` | 技能卡片里的副本列表、节点上的「副本 x/3」、分支头的星数合计 |
| `public/game-quests.js` | `drills`（副本 id → 最好星级）、`recordDrill()`，跟着存档一起保存 |
| `public/case-session.js` | 读副本的 `harder`：去掉提示、加干扰词、另存进度 |
| `test/game-drills.test.mjs` | 阶梯解锁、最好成绩、干扰词在样本代码里确实不存在、副本只挂在第一部的技能上 |

副本条目长这样：

```js
{ id: "privacy-2", tier: 2, title: "两种说法都像真的",
  why: "小词典混进两个干扰词，找错词就查不到东西。",
  harder: { hints: false, decoys: [{ zh: "键盘记录", code: "keyLogger" }, …] } }
```

## 5. 现在的边界

- 六个副本阶梯挂在**安全**分支的六个技能上，因为那六个委托已经能走进去。
- **AI 分支还没有副本**：主线章节还没做完，技能还没有 `from`，做一章补一章。
- 阿哲、周姐、王奶奶三关目前只有工作台分析、没有房间，所以它们的副本在树上是灰的，写着「这一关还没做成能走进去的房间」。
- 等 `docs/case-mechanics.md` 的六种专属玩法落地后，副本会复用同一套玩法引擎，只是参数更狠；副本不需要另写一份玩法。
