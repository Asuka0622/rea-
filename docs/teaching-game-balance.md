# 教学与好玩，怎么都要

更新：2026-10-17。回答「优化游戏机制，但这是教学游戏，两者要兼顾」。
结论先行：**教学和好玩不冲突，冲突的是「把知识塞进一个统一流程」。真正的解法是认知层统一、操作层变化。**

## 1. 先拆开：到底冲突在哪

现在六关共用一条流程（走→点→搜→填→验→辩），导致两件事同时受损：

- **教学侧**：学生学到的是「跟着问号走」，不是「怎么查一个软件」。换个陌生软件他不会——这是教学的硬伤，比不好玩严重得多。
- **游戏侧**：第二关就能预测全部流程，没有张力、没有失败、没有差异——这是好玩性的硬伤。

**根因是同一个**：一关一套流程 → 知识被流程稀释，同时流程本身没有变化。
所以修法不是「加点游戏性」，而是**同一套思维动作，换不同的手上动作**。

## 2. 核心原则：认知层统一，操作层变化

| 层 | 要什么 | 保证什么 |
|---|---|---|
| **认知层（教学）** | 六关都练同一套思维：看见现象 → 找到证据 → 给出解释 → 用证据回应说法 | 学习一致性、可迁移 |
| **操作层（游戏）** | 每关一个不同的手上动作：盖章、圈格子、连线路、排时间、按序列、编字段 | 新鲜感、差异、记忆点 |

这样教学不散（认知动作始终一致），游戏不腻（手上的活儿一直换）。

## 3. 六个壳子本身就是行业标准动作

这是「兼顾」最关键的一点：**别把玩法做成糖衣，玩法就是那个职业动作本身**。
玩得越深 = 学得越真，不需要额外加料。

| 壳子 | 手上的动作 | 教的知识点 | 对应的真实工作 |
|---|---|---|---|
| 审读台 | 一条承诺配一份证据，盖「说到了/没说/说反了」 | 隐私条款 vs 实际行为 | 隐私合规审查 |
| 排除网格 | 在文件堆里一格一格圈「这里有密钥」 | 密钥硬编码 | 发布前密钥自查 |
| 时间线排序 | 把 1.0 → 1.1 的变化拖到时间轴上 | 版本对比 | 补丁对比（安全行业日常） |
| 数据流连线 | 画线：灯要亮，数据不能走到出口 | 最小权限 | 权限评审 |
| 存档编辑 | 改字段、算校验和、写回副本 | 编码 ≠ 加密、校验和 | 存档/数据格式分析 |
| 输入序列 | 从残页推出按键顺序并亲手按出来 | 隐藏入口、彩蛋 vs 后门 | 客户端入口排查 |

## 4. 脚手架递减：难度来自「撤掉帮助」而不是「加内容」

教学上叫**认知 apprenticeship**（示范 → 辅助 → 独立），游戏上正好对应三层难度。
同一份内容，靠撤脚手架产生挑战，不用另做一套内容。

| 层 | 教学侧 | 游戏侧 | 撤掉什么 |
|---|---|---|---|
| **剧情关** | 有人带、有提示、错了不惩罚 | 一定能过，认识角色和故事 | — |
| **复勘（熟练 → 溯源 → 定案）** | 独立应用 | 记星级，错了记一次犯错 | 撤提示 → 加干扰 → 限时/一次机会 |
| **专家档（待做）** | **迁移**：换一个没见过的软件，用同一套方法 | 真正的挑战 | 撤掉整套熟悉的场景和角色 |

教学上最重要的一层是**专家档的迁移任务**：能不能在陌生软件上独立做一遍，是唯一能证明「学会了」的证据。
游戏上这一层也最耐玩，因为它是新的谜面，不是重播。

## 5. 犯错：教学要纠，游戏要有代价——用「可见但不惩罚」

- 判错了：立刻说清楚**为什么错**（教学），而不是只说「不对」。
  例：「这个其实用得上——很多安卓机型要把相机权限给了，才能控制闪光灯。」
- 代价：记一次犯错 → 影响星级和复盘（游戏张力），**但不卡关**（教学不劝退）。
- 关键：**可以无限重试，但记录会留着**。教学的纠错功能保住了，游戏的紧张感也有了。

## 6. 不要踩的两个坑

- **为好玩牺牲真实性**：别为了刺激把「配置文件加密」之类错的知识做进去——教学游戏的信誉一旦破了，游戏性也救不回来。
- **为教学把游戏做成问答**：现在的填词推理就有这个风险。原则是**学生做的动作 = 从业者做的动作**，
  如果从业者不用拖卡片填空，那就换掉这个动作（所以有了审读台、网格、连线这些壳子）。

## 7. 落地：一个字段 + 三个动作

- **数据字段**：`game.puzzle.scaffold: "guided" | "assisted" | "independent"`，
  决定这一关给不给提示、给不给干扰词、要不要时限。三档难度读的是同一个字段。
- **第一个动作**：把六个壳子里的「时间线排序」做出来（周姐那关，同时也是最后一块内容缺口）。
- **第二个动作**：目标条改成「委托人的请求」（不列待办），把探索的主动权还给学生——
  这一条同时提升游戏性和教学效果：学生必须自己决定「我该看什么」，这正是审计能力本身。
- **第三个动作**：加专家档迁移任务的骨架（同一个壳子 + 陌生样本），作为「学会了没」的验收。

## 8. 怎么验收（教学侧也要能量化）

1. **迁移测试**：给一个没见过的软件，让玩家独立做一遍——成功才算学会（现在还没有这一层）。
2. **错误类型统计**：玩家第一次判错集中在哪里，说明哪里教得不清楚（比通关率有用）。
3. **撤脚手架后是否还能过**：复勘「定案」档的通过率，是「真的会了」的直接指标。
4. **能不能说出方法**：结案复盘里让玩家用一句话总结「下次我怎么查」——说得出才算内化。

## 9. 一句话总结

**别在「加游戏性」和「保教学」之间做选择：把核心玩法换成从业者真正做的动作，
用撤脚手架产生难度，用可重试的犯错同时服务纠错和张力。这样学生练的是真本事，玩家玩的是真谜题。**
