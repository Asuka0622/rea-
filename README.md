# REA 工作台

给零基础用户的 [REA（Reverse Engineer Anything）](https://github.com/morluto/rea) 图形界面：
选一个软件 → 自动探索 → 打开宝箱，领取中文报告 → 按需要复制给 AI 继续解读。全程在本机运行，只读取文件，不运行它。

> 只分析你自己的软件，或你有权研究的软件。REA 项目明确不支持破解授权、外挂、绕过防护等用途。

## 怎么启动

1. 安装 [Node.js](https://nodejs.org/zh-cn/download) 22 或更新版本（LTS 即可）。
2. Windows 双击 `启动工作台.bat`；macOS 双击 `启动工作台.command`。
3. 浏览器会自动打开 `http://127.0.0.1:7321/`。关闭黑色窗口即退出。

命令行用户：`npm install` 后 `npm start`。

## 两种模式

右上角可以随时切换，工作台会记住你的选择。

- **🌱 新手模式**（默认）
  - 首页是四阶段像素冒险地图，可从示例开始，也可选择自己的文件。冒险指南可以随时打开。
  - 选择自己的文件后可展开任务入口：先看个示例、看电脑上的软件（自动列出可以分析的软件）、看手机 App、检查自己的安装包、让 AI 帮我分析。
  - 有新手教程页，共 8 课。
  - 报告里的专业词可以点开看解释，也可以在右上角的「小词典」里查。
  - 详细内容默认收起。
  - 「看不懂？让 AI 解释」会复制报告，并一步步教你粘贴给豆包、Kimi、DeepSeek 或通义千问。
- **🛠️ 专业模式**
  - 选择目标时可直接输入路径，并手动选择要运行的 REA 命令。
  - 报告全部展开，附带等价的命令行、原始 JSON 预览和下载。
  - 引擎页和接入页显示环境变量和配置文件路径。

## 能做什么

| 页面 | 作用 |
| --- | --- |
| 首页 | 选择文件或文件夹（APK、exe、dll、so、ipa、asar、zip、HAR、Electron 应用目录……），自动识别类型、选择合适的 REA 命令，把结果翻译成中文报告；报告里有「下一步」按钮，可以一键「复制给 AI」 |
| 分析引擎 | 检测并一键安装免费引擎：JDK 21+、Ghidra 12.1.4、JADX（REA 审核过的版本，会校验 SHA-256）、ADB、Apktool；付费引擎（Hopper、IDA、JEB）可以手动填写路径 |
| 接入 AI 工具 | **REA 官方不支持的**：Trae / Trae CN、Cline、Roo Code、Kilo Code、Kiro、LM Studio 一键写入配置；通义灵码、CodeBuddy、Cherry Studio、Qoder、JetBrains AI 等提供可直接复制的配置和操作步骤。**REA 官方支持的**：Claude Code、Codex、Cursor、Gemini CLI、Windsurf、Qwen Code、VS Code 等，调用 REA 自带的安装程序接入 |
| 状态检查 | 运行 `rea doctor`，用中文显示检查结果；可以一键移除所有 REA 接入 |

### 为小模型准备的两个开关

REA 一共有 170 个工具，工具定义合起来很大，国产模型和小模型容易用不好，有些客户端还会因为工具太多而报错。

- **新手精选**（默认开启）：AI 客户端连接的是 `mcp-proxy.mjs` 这个代理，它只把约 40 个常用工具交给 AI，其他工具对 AI 不可见，也不能调用。
- **精简模式**（默认开启）：使用 REA 自带的 compact 参数格式。

两个开关都开时，AI 要读的工具说明从约 425 KB 降到约 40 KB。这两个开关只对「工作台支持」和「复制粘贴」两组客户端生效；REA 官方支持的那组由 REA 自己写配置，始终是全部工具。

## 视觉设计

整个工作台采用像素 RPG 森林探险风格：

- **世界**：迷雾森林、流沙遗迹、霜雪古堡、枫叶秘境四张地图，打开或刷新时随机展示，并避免紧接着重复上一张。冒险者日志、羊皮纸面板与金色像素菜单保持统一。教程、分析引擎、接入 AI 工具和状态页使用同一套视觉系统。
- **四站**：选一个软件、认出它是什么（自动）、查看它的内部（自动）、打开宝箱。左侧任务面板一次只显示当前要做的事；宝箱直接出现在地图上。每张地图分别配置节点和角色坐标，节点会随画面缩放与裁切调整。探索中地图保持稳定，节点与向导对话跟随真实分析状态。
- **成果**：生成报告后解锁宝箱。用户点击开启按钮，箱盖弹起并出现像素光点，然后显示真实报告。取消和错误不会解锁成果。
- **字体与素材**：地图与透明道具由 ImageGen 生成；中文菜单使用本地 Fusion Pixel 字体（OFL 许可，许可文件随项目保留）；长报告正文保持普通字体，数据保持等宽字体。无远程字体请求。
- **可访问性**：支持键盘焦点、手机布局和系统「减少动态效果」设置。关闭动态效果时立即展开成果。右上角仍可切换浅色、深色或跟随系统。

设计细节见 DESIGN.md，生成素材记录见 .impeccable/assets/provenance.json。

## 安全设计

- 服务只监听 `127.0.0.1`，并且会检查 Host 头，防止 DNS 重绑定攻击。每个 API 请求都必须带上一个随机令牌，这个令牌只写在工作台自己的页面里，所以其他网站无法操控工作台。
- 修改 AI 工具配置前，会先展示要改哪个文件、改哪些内容；修改前自动备份原文件（`*.rea-workbench-<时间>.bak`）。只会增删名为 `rea` 的那一项。如果配置文件不是严格的 JSON（比如带注释），工作台会拒绝修改。
- 分析时只能运行白名单里的 REA 命令。下载的引擎在有官方校验值时都会校验 SHA-256，并且安装在工作台自己的目录里（`~/.rea-workbench/tools`），不改系统环境变量。

## 沙箱试用

```bash
node sandbox.mjs
```

沙箱模式会把用户目录、AppData 等都指向 `./.sandbox`。在这个模式下点「一键接入」「一键安装」，只会写进沙箱，不会碰到你真实的 AI 工具配置。

## 测试

```bash
npm test
```

冒烟测试会在 `test/.sandbox-smoke` 里启动一个独立的工作台，覆盖以下内容：分析 Electron 样本、exe 和 .NET dll；令牌和 Host 校验；客户端接入与断开；拒绝修改非标准 JSON；REA 官方接入流程；精选代理的工具过滤。另外还有下载校验的单元测试。

## 数据位置

`~/.rea-workbench/`（Windows 上是 `C:\Users\<你>\.rea-workbench\`）：

- `settings.json`：设置
- `tools/`：引擎
- `uploads/`：拖进来的文件
- `results/`：原始分析结果

删除这个文件夹即可清除工作台的所有数据。

## ArtCraft 开源演示

首页的「ArtCraft 开源演示」收录 PhotoCraft、VectorCraft、FilmCraft、LightCraft、PdfCraft、EffectCraft、DesignCraft 七款软件的固定版本完整源码。点击「分析源码」可扫描 Cargo 模块、Rust 文件、声明依赖和入口，再开箱查看报告或复制给 AI 学习。只读扫描，不编译、不运行源码；实际编辑功能通过各项目的官方入口体验。

源码位于 `samples/artcraft/`，上游许可证保留在各项目内；版本、来源和压缩包 SHA-256 记录于 `samples/artcraft/SOURCES.json`。此目录属于本机演示材料，Git 忽略其完整源码，复用时可运行 `scripts/prepare-artcraft.ps1` 重新下载固定版本。

## 游戏与 Mod 真实案例

用户要求的是网上已有的真实项目。首页现使用 tModLoader ExampleMod、CJB Cheats Menu、Fabric Example Mod、GDQuest Open RPG；与 ArtCraft 七款分开显示。四个完整上游源码快照保存在 `samples/games/`，原 ZIP 在 `.archives/`，固定提交、来源、SHA-256、许可证与大小见 `samples/games/SOURCES.json`。具体学习入口见 `samples/games/README.md`。可在页面查看原仓库、阅读源码入口并进行有界只读扫描；结果保存到项目 `data/game-mods/results/`。这是工作台的补充源码扫描，不代表上游使用 REA 制作；源码未编译、未在游戏内验证。此前原创教学样本保留在 `samples/game-mods/`，不再作为首页的真实案例展示。

## 人物模型 Mod 与工具 MCP

首页新增独立人物模型 Mod 指南：五步制作流程、六类工具、官方与社区 MCP 来源、AI 学习任务。支持选择或输入现有 Mod 目录，静态检查 INI 资源与缺失文件，通过冒险与宝箱查看报告。详见 `docs/model-mods/README.md`；来源记录见 `docs/model-mods/guide.json`。Blender Lab 官方 MCP 已核实（Blender 5.1+），当前未安装或连接外部 MCP；模型编辑、导出与游戏内效果仍需对应工具验证。

人物模型 Mod 区域跟随顶部新手/专业切换：新手提供按目标筛选工具的四步向导，专业提供完整资源规则、CLI 和 MCP 接入说明；路径与向导状态保留。

## 简洁与像素界面

顶部「切换到简洁 / 切换到像素」切换界面并记住选择。简洁模式移除地图、美术边框、像素字体和宝箱动画，文件表单与报告直接呈现。新手/专业与浅色/深色设置独立；切换时保留输入和已有报告。


## 新手报告阅读

新手模式先解释本次发现、部件分工与可学习的内容；名称含义推测会标注“可能是”。原始数据和代码线索可通过“查看专业细节与数据”展开，专业模式直接显示完整原报告。说明依据本次静态报告生成，不能代替运行验证；没有足够线索时会明确说明暂时无法判断。


报告有明确笔记功能线索时，新手可点击“开始这个练习”，直接获得一项小练习的说明书。首次进入预选网页形式和网页版 AI；已填写的目标或已有练习会保留。也可点击“自己选其他功能”继续使用完整向导。


## 粘贴 AI 网页代码并试用

网页练习第 4 步可粘贴 AI 的整段回答，点击“预览作品”进行隔离预览。支持单个 HTML 文件，输入上限 2 MiB；多文件项目、电脑软件和安卓项目按 AI 的项目说明运行。

本机可保存到工作台数据目录的 practice 文件夹，也可下载 HTML。保存和下载的是网页代码，不包含预览里临时填写的数据。开发沙箱当前位置为 D:\gpt\rea\.sandbox\workbench\practice。预览的联网及持久保存可能受限，请单独打开保存的文件，再测试关闭重开。


## AI 选择与账号风险

接入 AI 工具页、AI 解读弹窗和练习的 AI 步骤提供国产服务推荐及账号风险说明。新手优先使用豆包、Kimi、DeepSeek、千问官方网页版；编码推荐 Trae CN、CodeBuddy 国内站及 Qoder CN，并确认实际模型提供商。Codex、Claude 工具卡注明地区、授权及条款风险，避免将正常官方使用一概描述为会封号。国产服务同样需要遵守规则。

官方来源与 2026-10-14 核对记录见 [AI 选择与账号风险](docs/ai-services/README.md)。OpenAI API 的地区清单不替代 ChatGPT/Codex 服务规则。推荐不会自动安装、登录或切换模型。


## Unity 资源真实测试

工作台新增小型 UnityFS / UnityRaw / UnityWeb 自包含资源包识别、真实对象读取、资源参数表及 PNG 导出。首页输入 samples/unity/atlas_test.bundle 的绝对路径即可测试；新手提供阅读说明，专业模式显示对象和字段证据。本机已安装项目内 UnityPy 1.25.4 环境，使用官方仓库固定样本跑通 10 个对象、1 张 1024 × 512 贴图及 25 项资源参数。

输出位于 exports/unity 的独立目录，包含 PNG、evidence.json、report.md。安装、来源和限制见 [Unity 测试说明](docs/unity/README.md)。本轮是工作台新增的 UnityPy 分析入口，没有修改上游 REA MCP 工具列表；不等于已恢复完整游戏或原始脚本。


Unity 资源分析现支持 Mesh → OBJ：保留几何及可用 UV/法线，记录顶点、三角形和来源。真实平面网格样本 samples/unity/mesh_test.bundle 已导出验证；OBJ 不包含骨骼、动画、材质连接或场景变换，不能据此宣称可直接替换游戏人物。详见 docs/unity/README.md。
